## 开发调试

源码已新增“收藏夹 → 保存当前工作区…”及“追加已保存工作区”，将整组布局、标签和视图保存为当前配置旁 `Workspaces` 目录中的 `.qdr`。恢复前仍预览并备份，再追加到对应窗格；保存到其他目录只作为普通导出。此功能已通过构建和无窗口检查，已包含在 temp16，真实菜单操作待验收。见[工作区收藏](docs/workspace-favorites.md)。

需要 .NET 10 SDK。以下命令只用于源码开发，调试版配置写到 `src/.state/ExplorerDirs.ini`，与发布版隔离；若旧调试版有 `session.json`，首次运行会迁移：

```powershell
dotnet run --project .\src\ExplorerDirs.App\ExplorerDirs.App.csproj
```

构建：

```powershell
dotnet build .\src\ExplorerDirs.App\ExplorerDirs.App.csproj --configuration Release
```

仅准备隔离 GUI 验收副本（不启动窗口、不访问桌面）：

```powershell
pwsh -NoProfile -File .\src\ExplorerDirs.GuiSmoke\run.ps1 -PrepareOnly
```

每次在 `src/.state/gui-smoke/<唯一编号>/` 下生成独立程序、全新配置、可丢弃的文件操作样本及 `preparation.json`；清单记录 EXE/DLL 的 SHA-256 和待验收项目，状态为 `prepared-not-run`。这不是日常发布版，也不表示 GUI 验收通过。交互测试仍需空闲桌面、多个任务之间的独占交接和显式 `-AllowInteractiveDesktopControl`；该交互模式会另建一份测试副本。

只读崩溃摘要可运行 `powershell.exe -NoProfile -File .\scripts\crash-summary.ps1 -Days 30 -AsJson`，或加 `-AppName Q-Dir.exe` 查看对标程序。脚本同时报告事件条数和按进程 ID、创建时间去重的崩溃进程数，按版本归类；本项目还区分发布版、源码测试版和异常退出标记。输出不含完整路径或进程身份；故障模块名与退出标记都不能单独证明故障原因。脚本不启动两个程序。可用 `-ProfileDirectory` 指定复制到其他位置的发布版配置目录。[本机 Q-Dir 事件基线](docs/q-dir-crash-evidence-2026-10-16.md)。

`scripts/wer-dumps.ps1` 的默认 `Status` 和 `Preview` 只读，可按程序名查看或预览 WER 小型转储配置。`Enable` 需要管理员 PowerShell 和显式 `-ConfirmDiagnosticCollection`；`Disable` 只删除本工具仍拥有的专用键，保留转储供人工处理。隔离 HKCU 注册表冒烟已通过，真实系统 WER 键没有启用。转储可能包含私人数据，默认放在 LocalAppData，不纳入 Git。见[可靠性设计](docs/reliability-isolation-design.md)。

已有 Explorer Dirs 进程运行时，可先用 `Get-Process ExplorerDirs.App | Select-Object Id, StartTime` 选定实例，再执行 `powershell.exe -NoProfile -File .\scripts\perf-sample.ps1 -ProcessId <PID> -Samples 12 -IntervalMilliseconds 5000 -AsJson`。脚本只读采样工作集、私有内存、CPU、句柄与线程，不启动或控制 GUI，也不输出程序路径；可执行文件以 SHA-256 和“发布版/源码测试版/其他副本”标识。当前只有控制台进程的采样回归，尚无真实 Explorer Dirs 长时间运行数据。源码已减少周期保存时对隐藏标签的 Shell 查询：切换标签或布局前捕获其视图状态，隐藏后使用缓存；此优化尚待真实窗口验证。[Q-Dir 短时只读对标快照](docs/q-dir-performance-snapshot-2026-10-16.md)不能替代本程序测量。

`scripts/folder-verb.ps1` 已准备可逆的**可选**文件夹/磁盘右键入口。默认 `Status` 和 `Preview` 只读；启用要求发布版随附的 `FolderRoutingCapability.ini`、精确 SHA-256 和明确确认。当前 temp.54 发布包通过只读 Preview，目录参数能力清单与 EXE 哈希匹配；隔离注册表位置已验证启用、重复启用、外部修改保护及卸载。实际菜单显示和目录启动仍待空闲桌面验收。此入口不会更改文件夹默认打开动作或 Win+E，当前真实系统关联没有被修改。

源码中的同配置窗口文件夹请求使用命名管道转交；对连接后未发完整请求的客户端设置读取超时，避免阻塞下一次请求。路由器关闭时也会取消尚在等待窗口回调的请求并释放配置锁。客户端对异常回执保留“结果不确定”状态，不把它当作明确拒绝；运行中的窗口若长期不就绪仍可能令请求排队。空头、不完整负载、异常回执及关闭期间悬挂回调的控制台回归通过，真实窗口转交仍待验收，此改动已包含在 temp16。

## 当前边界

当前地址栏和会话支持普通文件系统路径，以及任何能由本机 Windows Shell 解析并确认为文件夹的绝对 Shell 解析名称；导入时无法解析或不再是文件夹的位置只影响对应标签。搜索结果是运行时虚拟 Shell 位置。文件操作、剪贴板、视图切换和第三方菜单由嵌入的 Windows Shell 视图提供；快捷键经 Shell 原生视图处理，未接手时使用原生 Shell 命令兜底。实际多窗格 Tab/Shift+Tab、重命名编辑、粘贴后方向键及 Shift+Delete 确认框焦点仍需真实窗口验收。导航历史仅在当前运行的各标签内保留，重启后恢复路径而非历史。跨窗格拖放、撤销、回收站和网络位置也需针对真实目录人工验收。第三方 Shell 扩展在本程序进程内运行，尚无扩展崩溃隔离。文件关联启动的程序不保证继承本程序刷新后的环境变量；热刷新承诺针对本程序直接创建的子进程，可用“在当前目录打开命令行”验证。系统右键菜单、文件夹背景目标和标签快捷关闭仍待用户在不同目录和窗口布局下预览确认。

搜索已接入原生 `search-ms:` 结果视图、窗格内输入框及搜索按钮、F3/Ctrl+E/Ctrl+F 和顶部菜单/工具栏入口；构建及无窗口回归通过并包含在 temp16。真实窗口中的结果、右键菜单、历史、焦点和非索引/网络目录响应仍待验收。[实现依据与验收边界](docs/search-research.md)。

故障报告请附 Windows 版本、复现步骤、目录类型和当时布局/标签数量；不要附个人目录内容或完整环境变量值。
