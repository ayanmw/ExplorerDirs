# Explorer Dirs

面向 Windows 的开源多窗格文件管理器。目标是替代日常使用的文件浏览窗口：以 Q-Dir 式布局和标签页为起点，优先解决崩溃后恢复、环境变量热刷新和可持续迭代。

> 当前为可运行预览版，不具备完整文件管理功能，也未接管 Win+E 或文件夹默认打开方式。不要把它设置为系统默认文件管理器。

## 已有功能

- 顶部菜单和图形快捷按钮切换单窗格、左右/上下双窗格、两种三窗格和四窗格；切换布局时保留各窗格标签页。
- 源码已加入“视图 → 紧凑布局”开关，收紧工具栏、窗格、导航按钮、标签和状态栏间距；默认保持原尺寸。设置独立保存在配置目录的 `UiPreferences.ini`，不影响旧预览版的会话文件。真实窗口排版待验收，尚未进入可用发布版。
- 每窗格多标签；标签右键菜单支持新建、复制、关闭其他和恢复关闭标签。中键或双击标签标题可关闭标签；每个窗格至少保留一个标签。标签栏单行显示，溢出时可用左右箭头或鼠标滚轮横向滚动。源码已支持同窗格拖动标题排序；Ctrl+Tab、标题方向键和重启快照按显示顺序工作，真实窗口效果待验收，新排序尚未进入可用发布版。
- 源码已加入固定标签：右键标签或文件视图中的项目前置菜单可固定/取消固定，固定标签排在窗格左侧；复制标签继承固定状态，快捷关闭与“关闭其他标签”会保留固定标签。固定元数据独立保存在配置目录的 `PinnedTabs.ini`，旧预览版保存会话不会直接删除该文件；若旧版改变标签位置或路径，新版会跳过不匹配的固定记录。真实窗口与重启恢复待验收，尚未进入可用发布版。
- 每个标签内嵌 Windows Shell ExplorerBrowser 文件视图，初始为详细信息。文件和目录空白处按系统视图命中，支持原生查看、排序、分组、新建、属性、文件关联、图标及第三方 Shell 扩展菜单；本程序的标签、路径命令排在同一个右键菜单前面。布局只在顶部菜单和快捷图标中切换。
- 源码已加入可点击的路径面包屑；Alt+D、Ctrl+L、Tab 导航或右侧“编辑”按钮进入完整路径输入，Esc 取消编辑。上级目录、刷新、双击打开文件或目录；每个标签独立的后退/前进历史与窗格导航按钮。Backspace / Alt+↑ 到上一级，Alt+←/→ 后退/前进；Tab / Shift+Tab 按相反方向依次经过各窗格的导航按钮、地址编辑、标签标题、详细信息列标题和文件列表，再进入相邻窗格；Ctrl+Tab 在当前窗格的标签间切换。布局切换后恢复该布局上次活动文件视图的焦点。面包屑真实交互待验收，尚未进入可用发布版。
- 恢复标签时保留暂时不可达的保存路径；目录可用性在后台探测，失败时显示状态并可用刷新重试。Shell 实际绑定网络目录仍需实机验收。
- 文件视图焦点落在 Shell 的实际内容控件；文件操作后恢复 Shell 文件项焦点，并处理 Shell 窗口关闭后短暂没有前台窗口的情况。地址栏、其他窗格或其他应用获得焦点时不会抢回焦点。
- 当前窗格可从文件菜单或工具栏新建文件夹，也支持 Ctrl+Shift+N；如果其他程序把该组合键注册为全局热键，请使用菜单或工具栏入口。
- 使用便携 INI 保存布局、默认新建标签查看方式，以及每个标签独立的路径、查看方式、图标大小、排序列和分组。复制标签复制当前视图设置；工具 → 选项 → 新建标签默认查看可改变新标签的默认方式。约每 3 秒检查视图变化并在变化后保存，关闭时再次保存。
- 发布版配置在项目根目录 `profile/ExplorerDirs.ini`，各 `releases/<version>/` 共用；独立复制某个发布目录时，配置在该目录的 `profile/` 下。首次运行会从旧版 `%LOCALAPPDATA%\ExplorerDirs\session.json` 迁移布局与路径，保留旧文件。旧版 Shell 视图状态不会自动迁入各标签。配置截断或标签计数损坏时，会先复制为同目录的 `.invalid-*.bak`，再恢复可读取的标签；高版本配置不会被旧程序覆盖。源码新增会话冲突保护：若配置在加载后被其他实例或编辑器修改，本实例停止覆盖并在状态栏报错；同版本实例写入由路径专属锁串行化，真实窗口提示待验收。
- 源码已支持向程序传入一个目录参数：恢复原会话后，在第一窗格新标签打开该目录；本地、UNC 和相对路径可由命令行传入，解析时不等待磁盘或网络。多个或非法参数只显示提示。此功能尚未经过真实窗口验收，也未进入可用发布版；当前不会接管 Win+E 或文件夹关联。
- 收到 Windows 环境设置变更消息时刷新当前进程的用户和机器环境变量，也可手动刷新；从当前目录启动的 `cmd.exe` 继承刷新后的环境。刷新时只读 Windows 持久化环境变量的原始值，以新快照展开变量引用并合并机器/用户 PATH，再更新本进程；不会写入注册表。
- 托管未处理异常会尝试在配置目录下的 `crash-logs/` 写入诊断文件。日志只包含异常类型、错误码和方法名，不包含异常消息、文件路径或环境变量；第三方 Shell 扩展的原生崩溃未必能被记录。
- 源码已加入顶部“收藏夹”菜单，可收藏、移除当前目录，并在当前窗格打开收藏目录。列表单独保存为配置目录下的 `Favorites.ini`，与会话 INI 及旧预览版隔离；损坏文件先备份，同一文件被其他实例修改时停止覆盖，同版本实例写入同一收藏夹文件时串行化。菜单和导航效果待真实窗口验收，尚未进入可用发布版。

## 预览发布版

在 Windows 10/11 且安装 .NET 10 Windows Desktop Runtime 的环境中，从 [`releases`](releases/README.md) 下最新版本目录启动 `ExplorerDirs.App.exe`。发布目录与源码编译输出相互独立；当前版本位置会写在该目录的说明中。

## 开发调试

需要 .NET 10 SDK。以下命令只用于源码开发，调试版配置写到 `src/.state/ExplorerDirs.ini`，与发布版隔离；若旧调试版有 `session.json`，首次运行会迁移：

```powershell
dotnet run --project .\src\ExplorerDirs.App\ExplorerDirs.App.csproj
```

构建：

```powershell
dotnet build .\src\ExplorerDirs.App\ExplorerDirs.App.csproj --configuration Release
```

## 当前边界

当前应用的地址栏与会话仅支持普通文件系统目录。文件操作、剪贴板、视图切换和第三方菜单由嵌入的 Windows Shell 视图提供；已接入 WPF 到 Shell 视图的快捷键转发，并为 Shell 未处理的 Ctrl+A/C/V/X/Z 调用原生 Shell 命令。隔离测试已验证详细信息视图的正反向 Tab 和复制粘贴后的方向键；四窗格及 Shift+Delete 确认框返回仍需用户在真实窗口中验收。导航历史仅在当前运行的各标签内保留，重启后恢复路径而非历史。跨窗格拖放、撤销、回收站和网络位置也需针对真实目录人工验收。第三方 Shell 扩展在本程序进程内运行，尚无扩展崩溃隔离。文件关联启动的程序不保证继承本程序刷新后的环境变量；热刷新承诺针对本程序直接创建的子进程，可用“在当前目录打开命令行”验证。系统右键菜单与标签快捷关闭仍待用户在不同目录和窗口布局下预览确认。

故障报告请附 Windows 版本、复现步骤、目录类型和当时布局/标签数量；不要附个人目录内容或完整环境变量值。
