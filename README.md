# Explorer Dirs

面向 Windows 的开源多窗格文件管理器。目标是替代日常使用的文件浏览窗口：以 Q-Dir 式布局和标签页为起点，优先解决崩溃后恢复、环境变量热刷新和可持续迭代。

> 当前为可运行预览版，不具备完整文件管理功能，也未接管 Win+E 或文件夹默认打开方式。不要把它设置为系统默认文件管理器。

## 已有功能

- 顶部菜单和图形快捷按钮切换单窗格、左右/上下双窗格、两种三窗格和四窗格；切换布局时保留各窗格标签页。
- 源码已加入“视图 → 紧凑布局”开关，收紧工具栏、窗格、导航按钮、标签和状态栏间距；默认保持原尺寸。设置独立保存在配置目录的 `UiPreferences.ini`，不影响旧预览版的会话文件。真实窗口排版待验收，尚未进入可用发布版。
- 每窗格多标签；标签右键菜单支持新建、复制、关闭其他和恢复关闭标签。中键或双击标签标题可关闭标签；每个窗格至少保留一个标签。标签栏单行显示，溢出时可用左右箭头或鼠标滚轮横向滚动。源码已支持同窗格拖动标题排序；Ctrl+Tab、Ctrl+1～9、标题方向键和重启快照按显示顺序工作，真实窗口效果待验收，新排序尚未进入可用发布版。
- 源码已让切换标签和布局时保留已访问的 Shell 视图与窗格对象，减少因 WPF 卸载视图造成的后退历史丢失风险。无窗口可视树回归通过；真实 ExplorerBrowser 句柄与历史保持仍待 GUI 验收，尚未进入可用发布版。
- 源码已加入固定标签：右键标签或文件视图中的项目前置菜单可固定/取消固定，固定标签排在窗格左侧；复制标签继承固定状态，快捷关闭与“关闭其他标签”会保留固定标签。固定元数据独立保存在配置目录的 `PinnedTabs.ini`，旧预览版保存会话不会直接删除该文件；若旧版改变标签位置或路径，新版会跳过不匹配的固定记录。真实窗口与重启恢复待验收，尚未进入可用发布版。
- 每个标签内嵌 Windows Shell ExplorerBrowser 文件视图，初始为详细信息。文件和目录空白处按系统视图命中，支持原生查看、排序、分组、新建、属性、文件关联、图标及第三方 Shell 扩展菜单；本程序的标签、路径命令排在同一个右键菜单前面。布局只在顶部菜单和快捷图标中切换。
- 源码已改为根据 Shell 选中项属性显示文件夹的“在新标签页中打开”命令，构建菜单时不再额外同步检查目录是否存在；真实右键菜单和网络目录的响应仍待 GUI 验收，尚未进入可用发布版。
- 源码已限制右键菜单前置命令只接收 Windows 标记为菜单来源的 `WM_COMMAND`，控件通知和加速键消息不会误触发；插入失败的命令也不会注册回调。控制台消息分类回归通过，实际 Shell 菜单执行仍待 GUI 验收，尚未进入可用发布版。
- 源码已加入可点击的路径面包屑；Alt+D、Ctrl+L、F4、Tab 导航或右侧“编辑”按钮进入完整路径输入，Esc 取消编辑。上级目录、刷新、双击打开文件或目录；每个标签独立的后退/前进历史与窗格导航按钮。Backspace / Alt+↑ 到上一级，Alt+←/→ 后退/前进；Tab / Shift+Tab 按相反方向依次经过各窗格的导航按钮、地址编辑、标签标题、详细信息列标题和文件列表，再进入相邻窗格；F6 / Shift+F6 在地址、标签标题、可用的列标题及文件区间跳转；Ctrl+Tab 在当前窗格的标签间切换。布局切换后恢复该布局上次活动文件视图的焦点。面包屑及 F6 真实交互待验收，尚未进入可用发布版。
- 恢复标签时保留暂时不可达的保存路径；目录可用性在后台探测，权限不足交给 Shell 自行处理，其他预检失败时显示状态并可用刷新重试。Shell 实际绑定无权限或网络目录仍需实机验收。
- 文件视图焦点落在 Shell 的实际内容控件；文件操作后恢复 Shell 文件项焦点，并处理 Shell 窗口关闭后短暂没有前台窗口的情况。地址栏、其他窗格或其他应用获得焦点时不会抢回焦点。
- 源码已限制 UI Automation 的“选中项聚焦”补救只在 Shell 明确报告单选时执行；多选时保留 `IFolderView` 指定的原焦点项，避免任意跳到列表中第一个选中项。多选复制/粘贴与确认框返回后的实际焦点仍待 GUI 验收，尚未进入可用发布版。
- 当前窗格可从文件菜单或工具栏新建文件夹，也支持 Ctrl+Shift+N；如果其他程序把该组合键注册为全局热键，请使用菜单或工具栏入口。
- `src/ExplorerDirs.GuiSmoke/run.ps1` 已改为隔离布局、目录往返及搜索测试：显式启用后才启动测试副本，配置写在 `src/.state/gui-smoke/`，通过 UI Automation 调用按钮，不发送键鼠输入或改动剪贴板。脚本会在该次隔离测试目录写入不含浏览路径的 `performance.json`，记录窗口、首次文件项、目录往返和搜索结果的探索性耗时。当前尚未在真实窗口重新运行；只在桌面空闲时启用。
- 源码已移除新建文件夹前后的全目录同步枚举；固定本地盘仅短时观察新目录并在 Shell 焦点吻合时尝试自动重命名，网络和非固定盘直接交给 Shell。大目录响应与实际重命名尚待 GUI 验收，未进入可用发布版。
- 使用便携 INI 保存布局、活动窗格、每窗格按标题显示顺序选中的标签、默认新建标签查看方式，以及每个标签独立的路径、查看方式、图标大小、排序列和分组。复制标签复制当前视图设置；实时视图配置读取失败时暂不复制该标签，也不以旧缓存覆盖会话 INI。工具 → 选项 → 新建标签默认查看可改变新标签的默认方式。切换标签/窗格会延迟保存，约每 3 秒检查视图变化，关闭时再次保存；活动位置的真实重启恢复待 GUI 验收。
- 发布版配置在项目根目录 `profile/ExplorerDirs.ini`，各 `releases/<version>/` 共用；独立复制某个发布目录时，配置在该目录的 `profile/` 下。首次运行会从旧版 `%LOCALAPPDATA%\ExplorerDirs\session.json` 迁移布局与路径，保留旧文件。旧版 Shell 视图状态不会自动迁入各标签。配置截断或标签计数损坏时，会先复制为同目录的 `.invalid-*.bak`，再恢复可读取的标签；高版本配置不会被旧程序覆盖。源码新增会话冲突保护：若配置在加载后被其他实例或编辑器修改，本实例停止覆盖并在状态栏报错；同版本实例写入由路径专属锁串行化，真实窗口提示待验收。
- 高版本会话 INI 即使出现重复的 `FormatVersion`，旧程序也停止写入；这项保护已通过控制台回归，真实启动提示待验收。
- 源码已支持向程序传入一个目录参数：优先转发给使用同一配置的现有窗口，在它的第一窗格新建标签并确认后退出启动进程；没有可用接收进程时恢复原会话并在新窗口的第一窗格打开。进程通信限制为同一用户及权限级别，不同步探测目标目录；本地、UNC 和相对路径可从命令行传入。多个或非法参数只显示提示。通信与并发回归已通过，真实窗口、激活和离线目录仍待 GUI 验收，尚未进入可用发布版；当前不会接管 Win+E 或文件夹关联。
- 收到 Windows 环境设置变更消息时刷新当前进程的用户和机器环境变量，也可手动刷新；从当前目录启动的 `cmd.exe` 继承刷新后的环境。刷新时只读 Windows 持久化环境变量的原始值，以新快照展开变量引用并合并机器/用户 PATH，再更新本进程；不会写入注册表。计划先整体校验，写入失败时恢复本轮已完成的进程变量改动，恢复失败会报错。无窗口回归已验证删除旧变量、新开隐藏命令行继承新值及中途失败回滚；真实通知和发布版可见命令行仍待验收。
- 源码中的“在当前目录打开命令行”改为后台启动系统目录下的 `cmd.exe`，不再在窗口线程同步探测目录或依赖已刷新的 PATH 寻找程序；关闭窗口会取消尚未启动的请求。无窗口回归验证了后台执行、启动参数及取消，真实慢速目录和环境继承仍待 GUI 验收，尚未进入可用发布版。
- 托管未处理异常会尝试在配置目录下的 `crash-logs/` 写入诊断文件。日志只包含异常类型、错误码和方法名，不包含异常消息、文件路径或环境变量；第三方 Shell 扩展的原生崩溃未必能被记录。
- 源码已加入每实例运行标记：正常退出清理，异常结束后下次启动提示已尝试恢复保存的会话，并在 `crash-logs/` 保留不含浏览路径的退出记录。同名退出记录已存在时保留旧文件，将新标记归档到唯一文件名，避免重复提示。标记无法证明是某个扩展崩溃；真实故障恢复还未经过窗口验收，尚未进入可用发布版。
- 源码已加入顶部“收藏夹”菜单，可收藏、移除当前目录，并在当前窗格打开收藏目录。列表单独保存为配置目录下的 `Favorites.ini`，与会话 INI 及旧预览版隔离；损坏文件先备份，同一文件被其他实例修改时停止覆盖，同版本实例写入同一收藏夹文件时串行化。菜单和导航效果待真实窗口验收，尚未进入可用发布版。

## 开发调试

需要 .NET 10 SDK。以下命令只用于源码开发，调试版配置写到 `src/.state/ExplorerDirs.ini`，与发布版隔离；若旧调试版有 `session.json`，首次运行会迁移：

```powershell
dotnet run --project .\src\ExplorerDirs.App\ExplorerDirs.App.csproj
```

构建：

```powershell
dotnet build .\src\ExplorerDirs.App\ExplorerDirs.App.csproj --configuration Release
```

只读崩溃摘要可运行 `powershell.exe -NoProfile -File .\scripts\crash-summary.ps1 -Days 30 -AsJson`，或加 `-AppName Q-Dir.exe` 查看对标程序。脚本同时报告事件条数和按进程 ID、创建时间去重的崩溃进程数，按版本归类；本项目还区分发布版、源码测试版和异常退出标记。输出不含完整路径或进程身份；故障模块名与退出标记都不能单独证明故障原因。脚本不启动两个程序。可用 `-ProfileDirectory` 指定复制到其他位置的发布版配置目录。[本机 Q-Dir 事件基线](docs/q-dir-crash-evidence-2026-10-16.md)。

`scripts/wer-dumps.ps1` 的默认 `Status` 和 `Preview` 只读，可按程序名查看或预览 WER 小型转储配置。`Enable` 需要管理员 PowerShell 和显式 `-ConfirmDiagnosticCollection`；`Disable` 只删除本工具仍拥有的专用键，保留转储供人工处理。隔离 HKCU 注册表冒烟已通过，真实系统 WER 键没有启用。转储可能包含私人数据，默认放在 LocalAppData，不纳入 Git。见[可靠性设计](docs/reliability-isolation-design.md)。

已有 Explorer Dirs 进程运行时，可先用 `Get-Process ExplorerDirs.App | Select-Object Id, StartTime` 选定实例，再执行 `powershell.exe -NoProfile -File .\scripts\perf-sample.ps1 -ProcessId <PID> -Samples 12 -IntervalMilliseconds 5000 -AsJson`。脚本只读采样工作集、私有内存、CPU、句柄与线程，不启动或控制 GUI，也不输出程序路径；可执行文件以 SHA-256 和“发布版/源码测试版/其他副本”标识。当前只有控制台进程的采样回归，尚无真实 Explorer Dirs 长时间运行数据。源码已减少周期保存时对隐藏标签的 Shell 查询：切换标签或布局前捕获其视图状态，隐藏后使用缓存；此优化尚待真实窗口验证。[Q-Dir 短时只读对标快照](docs/q-dir-performance-snapshot-2026-10-16.md)不能替代本程序测量。

`scripts/folder-verb.ps1` 已准备可逆的**可选**文件夹/磁盘右键入口。默认 `Status` 和 `Preview` 只读；启用时要求未来发布版随附的 `FolderRoutingCapability.ini`、精确 SHA-256 和显式 GUI 验收确认。当前 `preview-0.5.2` 缺少单目录参数能力清单，脚本会拒绝将它设为入口目标。隔离注册表位置已验证启用、重复启用、外部修改保护及卸载；真实菜单显示和启动仍待空闲桌面验收。此入口不会更改文件夹默认打开动作或 Win+E，当前系统关联没有被修改。

源码中的同配置窗口文件夹请求使用命名管道转交；对连接后未发完整请求的客户端设置读取超时，避免阻塞下一次请求。路由器关闭时也会取消尚在等待窗口回调的请求并释放配置锁。客户端对异常回执保留“结果不确定”状态，不把它当作明确拒绝；运行中的窗口若长期不就绪仍可能令请求排队。空头、不完整负载、异常回执及关闭期间悬挂回调的控制台回归通过，真实窗口转交仍待验收，此改动尚未进入可用发布版。

## 当前边界

当前应用的地址栏与会话仅保存普通文件系统目录；搜索结果是运行时虚拟 Shell 位置。文件操作、剪贴板、视图切换和第三方菜单由嵌入的 Windows Shell 视图提供；已接入 WPF 到 Shell 视图的快捷键转发，并为 Shell 未处理的 Ctrl+A/C/V/X/Z 调用原生 Shell 命令。旧预览版隔离测试已验证详细信息视图的正反向 Tab 和复制粘贴后的方向键；持久内容层改动、四窗格及 Shift+Delete 确认框返回仍需用户在真实窗口中验收。导航历史仅在当前运行的各标签内保留，重启后恢复路径而非历史。跨窗格拖放、撤销、回收站和网络位置也需针对真实目录人工验收。第三方 Shell 扩展在本程序进程内运行，尚无扩展崩溃隔离。文件关联启动的程序不保证继承本程序刷新后的环境变量；热刷新承诺针对本程序直接创建的子进程，可用“在当前目录打开命令行”验证。系统右键菜单与标签快捷关闭仍待用户在不同目录和窗口布局下预览确认；空白处右键时若仍有选中项，前置命令的目标也需要单独验收。

搜索源码已接入原生 `search-ms:` 结果视图、窗格内输入框及搜索按钮、F3/Ctrl+E/Ctrl+F 和顶部菜单/工具栏入口；构建及无窗口回归通过。当前尚未在真实窗口验证结果、右键菜单、历史、焦点和非索引/网络目录响应，因此未发布新的可用版本。[实现依据与验收边界](docs/search-research.md)。

故障报告请附 Windows 版本、复现步骤、目录类型和当时布局/标签数量；不要附个人目录内容或完整环境变量值。
