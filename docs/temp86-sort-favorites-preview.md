# temp.86 排序与收藏夹交互修订预览（2026-11-05）

## 本批变化

- 非混合排序不再抵消类别方向，不再两个方向都强制目录在前。修正行序验证器对应的旧断言。
- 普通列标题方向切换不再启动反向/恢复定时流程。首次异步大小补值改为等待值就绪、保留主排序方向并通过原生排序键重排；对已知数值仍验证行序，失败最多三次后明确停止。大小分组启动仍保留一次必要的初始化枚举。
- 混合开关扩展到名称、修改日期、类型等列，不再依赖显示文件夹大小；旧INI字段MixedSizeSort保持兼容。排序策略需要的原生namespace路由与大小计算开关分离。
- 关闭文件夹大小时，Size采用底层原生文件夹比较，忽略混合开关；目录名称在两个方向都保持正序。名称使用自然排序；身份比较仍独立于排序策略。
- 管理收藏夹/常用位置改为即时保存、添加目录选择器、拖动目标提示及目标组展开；取消保存/取消按钮。失败提示并在关闭时保护未保存修改。

## 验证与边界

- 原生DLL、App及探针构建成功。实际原生视图中验证Size分类/混合双向、Name和Date分类/混合双向、独立同路径标签策略及关闭大小时两种混合状态行序一致。诊断用例自动通知枚举计数delta=0。
- 实际未显示收藏夹窗口：真实按钮、生产保存回调，五次修改各一次即时磁盘写入，由新读取器重新读回。
- 正常产品完整App两进程50652/70840功能通过：外部目录/文件/连续文件变化、37KB→83KB重建及重命名、四窗格五标签会话写回及窗口位置恢复。此前候选的拒绝会话写回失败已由该对照替代。
- 后台总检23步骤通过后在前台保护断言失败；其余6步骤单独通过，不能写整轮全绿。各原生视图/完整App诊断执行期间检测到外部输入，前台保持不变，隔离守卫未通过；功能证据与守卫结果分别记录。
- 尚需用户可见验收：反复点击列标题是否停止循环、实际闪烁和焦点、Type及其他属性列、多DPI、目录选择器、真实拖放及窗口关闭重开。
- 原有大目录自动删除残留/短暂空列表仍未关闭，不包含被否决的四次删除重验方案；本预览不代表整个temp.86路线图全部完成。F5保留手动完整刷新。

## 集中验收步骤

1. 关闭混合、开启文件夹大小，连续点击Size列标题至少6次；应只在两种稳定行序之间切换，等待后不自行反复重排，鼠标无需点击文件区打断。
2. 开/关混合，分别点击名称、修改日期、类型与Size，确认类别划分、方向及选区/焦点；关闭文件夹大小后再对比Size，两种混合状态应相同且目录内部名称正序。
3. 管理收藏夹：新建组、选择目录添加、重命名、拖到组内/根目录、上下移动；确认目标提示，直接关闭再打开，应立即保留改动，无需保存按钮。常用位置同样检查。
4. 退出重开，核对布局、标签及混合状态。构建身份见关于→版本信息。
