# 临时预览 temp.43

## 本版内容

此预览基于 temp.42 之后的当前源码，采用独立 profile。主要新增和修正包括：

- Q-Dir 标签查看模式按官方 1–7 范围导入；不支持的 Content 模式导出为 Q-Dir 兼容的详细信息，同时由 Explorer Dirs 扩展保留本程序状态。
- `.qdr` 导入预览说明未识别字段和暂不支持的位置/颜色字段，并补齐十二种布局下的窗格与目录树映射回归。
- 文件视图状态、Shell 文件操作焦点、多选恢复、自动刷新计数与变更通知处理继续完善；并增加地址栏历史、现代地址栏 F4 目录树、搜索虚拟 Shell 位置等能力。
- 隔离 `IShellView` 颜色原型确认可保留部分原生菜单、选择和拖放接口，但隐藏绘制没有提供可验证的逐项颜色像素。本版没有把原型迁入产品视图，Q-Dir 行着色与导入后黑底仍未解决。

## 已验证

- Release SettingsSmoke 全量通过。
- App、NativeProbe、HostProbe Release 构建通过，0 警告、0 错误。
- 隔离发布 smoke 通过；隐藏 `IShellView` 颜色探针通过且确认前台窗口不变、父窗口不可见。
- 发布目录中的 EXE/DLL SHA-256 与包内清单一致；程序集产品版本为 `0.6.0-preview.temp.43+77495f5d72a4739c2bb33a21d021328294f728c0`。
