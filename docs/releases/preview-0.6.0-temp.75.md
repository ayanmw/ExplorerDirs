# Explorer Dirs Preview 0.6.0 temp.75

发布目录：`D:\projects\explorer-dirs\releases\preview-0.6.0-temp.75`。
入口：`app\ExplorerDirs.App.exe`。配置从 temp.74 的 `app\profile` 复制到本版独立 `app\profile`，不会与源码调试或旧版本共写同一 profile。复制使用发布脚本的明确白名单，不复制锁、历史备份或无关文件。

## 相比 temp.74 的累计产品变化

- 默认记住每个窗口的位置、大小及最大化状态；恢复最小化窗口保留最大化状态，新窗口按来源显示器错位放置。混合 DPI/断屏仍需实际验收。
- 主工具栏移除剪切、复制、粘贴、删除、重命名、撤销、重做，继续由编辑菜单和快捷键提供。
- 跨窗格移动标签保留宿主与导航历史，Ctrl 拖动复制；固定标签顺序与关闭清理修复。可选多行标签栏、拖动悬停切换、空白标签栏双击新建、以当前目录新建标签。
- 现代地址栏空白/分隔符点击进入编辑；下载目录由 Shell 定位；迟到导航/搜索结果保护新输入，复制/关闭恢复使用浏览器已确认目录，恢复关闭标签保留独立地址 MRU。
- Home/End/PageUp/PageDown 与方向键保留原生文件区/重命名编辑路由；文件快捷键只在 Shell 明确未处理时补发，文件操作及切换窗口后的焦点恢复保护进一步完善。
- 可选复选框/整行选择、状态栏与选中大小显示、未选中时当前目录可取得大小；显式所选项目递归扫描，不跟随重解析点；退休扫描失败不清除新结果。
- 快速筛选历史补全、附件失败回滚、临时分组保护；视图恢复失败时保护旧的模式/列/排序/分组配置。
- 窗口关闭主动释放自有 Shell 宿主；QDR/工作区/视图导出停止已关闭界面的等待与更新。照片打印防重复及迟到预览保护；隐藏窗格不执行悬停回调。
- 应用图标缓存为 256 项 LRU，目录树/虚拟位置图标路径修复；F11 保留应用菜单、工具栏、状态栏；滚轮焦点和矢量图标/焦点色细节更新。

## 验证与限制

完整 Release SettingsSmoke 和发布隔离 smoke 已通过。发布包包含构建版本和 `app\SHA256.txt`，发布后另核对确切 EXE/DLL 哈希、版本与 profile。没有启动本预览；当前禁止 Computer Use 的约束继续有效，因此不将本包称为已通过真实启动/GUI 验收的稳定版本。

本版仍使用 ExplorerBrowser。IShellView 逐项颜色、派生文件夹大小列和完整迁移没有接入产品。QDR 已有导入/导出链路，但 Q-Dir 自身读取与再保存不等于本程序自测；真实 F2、粘贴/删除后焦点、正反 Tab、右键背景命中、多屏及运行期内存仍待可见验收。

首次预览优先比较：工具栏、窗口位置恢复、标签拖动与多行显示；随后在可丢弃文件中检查 F2、粘贴/删除后的方向键、分组筛选与重启恢复。不要在未核对行为前以唯一文件进行删除/移动验收。
