# 0.6.0 临时预览第七版

日期：2026-10-24。目录版本：`preview-0.6.0-temp.7`；程序集版本：`0.6.0-preview.temp.7`。

此包从当前源码构建，配置放在 `app/profile/`，与日常 profile 和 `src` 调试目录隔离。它用于预览路线图进展；本包未启动 GUI，也未完成 Shell/Q-Dir 可见互操作验收。旧版本保留，不覆盖。

## 相对 temp.6 的主要变化

- **文件视图中键开文件夹：**文件列表按点击坐标命中 UI Automation 列表项，读取其标签名，在当前文件系统目录下构造候选路径，再让 Windows Shell 确认其为同名、同父目录的普通文件夹后打开新标签。空白、表头、搜索/虚拟位置不使用残留选区；若导航、视图或用户输入在异步探测期间变化，则丢弃请求。
- **目录树中键开文件夹：**Shell 原生目录树点击回调提供精确的 `IShellItem`，普通文件系统目录在新标签打开。
- 新标签沿用详细信息默认查看方式；本轮新增路径检查和异步请求失效回归。

## 隔离与启动

运行 `app/ExplorerDirs.App.exe`，需要 .NET 10 Windows Desktop Runtime。配置位于包内 `app/profile/`；本包独立保存，不写入项目根目录日常 profile。请从本目录启动，不要运行 `src` 下的调试构建，也不要在程序运行期间覆盖包目录。`app/SHA256.txt` 记录 EXE 与 DLL 的 SHA-256。

## 验证边界

- App Release 构建无警告/错误；Release SettingsSmoke 全量通过；发布隔离 smoke 通过。
- 未启动应用 GUI，也未模拟物理输入。UI Automation 是否能在实际 ExplorerBrowser 文件视图里准确命中每种查看方式下的行，以及可见中键、焦点和新标签行为，仍待桌面验收。
- 复制、粘贴、删除确认/回收站、撤销、重命名、菜单及工具栏、焦点遍历、多窗口和重启、打印预览与 Q-Dir 实际 `.qdr` 互操作仍需可见验收。
- 自动刷新在大目录、网络和离线位置仍有未关闭的性能问题；第三方 Shell 扩展仍在应用进程内运行。

请只在隔离包中预览；如果中键未生效或打开了错误目录，请反馈使用的查看方式、点击位置、预期和实际结果。
