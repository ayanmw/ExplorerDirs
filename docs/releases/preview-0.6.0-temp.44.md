# 临时预览 temp.44

## 本版内容

相较 temp.43，本版增加 Q-Dir 风格的列标题快捷操作：按住 Ctrl 右键单击 Shell 文件视图的列标题，可打开命名视图预设菜单，保存当前窗格列布局或应用已有预设。普通右键、键盘上下文菜单和文件项右键仍交给原生 Shell 菜单。

此版本使用包内独立 profile，不会覆盖 temp.43 或日常使用配置。
