# 0.6.0 临时预览第九版

日期：2026-10-24。目录版本：`preview-0.6.0-temp.9`；程序集版本：`0.6.0-preview.temp.9`。

本包从当前源码构建，程序和配置均位于 `app/`，独立于日常 profile 与 `src` 调试目录。它汇总 temp.8 之后的 Shell 交互、标签/窗口会话、Q-Dir 状态文件和状态栏工作。没有启动可见 GUI；隐藏生产宿主及无窗口 smoke 不代表已经通过实际键鼠或 Q-Dir 界面验收。

## 主要功能

- **文件视图和快捷操作：**每窗格继续使用 Windows ExplorerBrowser/Shell 视图；保留 Shell 原生文件和空白处右键菜单，自定义标签/布局命令放在前面。菜单、工具栏与快捷键复用原生文件命令。Ctrl+鼠标滚轮循环八种查看方式，文件项、排序/分组和列设置按标签保存。
- **标签和窗口：**支持新建、复制、关闭、恢复、固定及排序标签；Ctrl+N 创建使用独立 INI 会话的新窗口，启动时按窗口清单恢复。普通新标签默认详细信息视图，复制标签继承查看、排序、分组、列和筛选配置。
- **Q-Dir 状态文件：**可导入 `.qdr` 工作区并预览、备份后追加布局与标签；支持导出 Q-Dir 可读布局/视图状态及本程序扩展配置。已通过本机 Windows Shell 原生视图状态流读回，不代表 Q-Dir 已实际读取或保存本包文件。
- **搜索与工作区：**每标签快速筛选和可保存筛选预设；支持目录树、Shell 搜索位置、收藏夹和 `.qdr` 工作区保存。
- **视图辅助：**当前文件视图可导出 CSV/TXT/HTML/XLS，并按当前查看方式准备打印布局；提供选择/容量等状态信息以及逐标签预览/详情窗格开关。
- **实时更新和焦点：**目录监视器在 Shell 枚举稳定期间保持运行；创建/删除通知合并，保留计数兜底。文件操作后有界恢复 Shell 视图焦点和选择；探针覆盖多窗格重命名方向键分派。

## 启动

运行 `app/ExplorerDirs.App.exe`，需要 .NET 10 Windows Desktop Runtime。程序配置保存在 `app/profile/`。请从本目录启动，不要运行 `src` 下的调试构建，也不要在程序运行时覆盖本包。`app/SHA256.txt` 记录 EXE 和 DLL 的 SHA-256。
