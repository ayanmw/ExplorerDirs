# Explorer Dirs 0.6.0 临时预览版 60

此包汇总 temp.59 之后的主题基础接线、活动窗格强调色标记和地址栏祖先层级菜单改进。项目仍处于 Q-Dir 功能与体验追赶阶段；本版没有完成可见 GUI 或实际 Q-Dir 互操作验收。

## 本版变化

- 地址栏位置下拉按根目录到当前目录组成可展开的祖先菜单树，当前目录显示勾选标记；桌面、下载、文档、此电脑、库、网络、控制面板和回收站等常用位置继续独立列出，图标由 Windows Shell 提供。
- 主题基础色板读取 Windows 强调色，浅色/深色模式均使用系统强调色；活动窗格边框随强调色变化。
- 主题用户首选项仍存放在独立 profile，Q-Dir 配置导入不改变全局主题。

## 验证与限制

- `AddressPathMenuSmoke`、主题色板和活动窗格接线 smoke、完整 Release `SettingsSmoke` 通过。
- App Release 构建 0 警告、0 错误；发布隔离 profile smoke 通过。
- 未启动程序窗口、未操作桌面、未启动 Q-Dir。地址下拉实际展开/鼠标行为、主题颜色变化通知、多窗口/高对比度/DPI、Shell 文件区呈色和 Q-Dir 实际读写仍待可见验收。
- 本预览使用 `app/profile/` 独立配置；从包内 `app/ExplorerDirs.App.exe` 启动，不要运行 `src/` 下的调试构建。
