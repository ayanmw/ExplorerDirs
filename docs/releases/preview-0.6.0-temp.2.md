# 0.6.0 临时预览第二版

日期：2026-10-21。目录版本：`preview-0.6.0-temp.2`；程序集版本：`0.6.0-preview.temp.2`。

用户要求先发布预览。本包包含当前源码，尚未通过精确发布二进制的 GUI 启动及完整操作验收。请先用临时文件试用；0.5.2 和 temp.1 均保留。

## 启动与配置

- 运行本目录 `app/ExplorerDirs.App.exe`。需要 .NET 10 Windows Desktop Runtime。
- 配置使用本包 `app/profile/`，打包时复制项目日常 profile 中现有的会话、收藏、固定标签与界面偏好 INI；不会使用源码调试配置，也不写回日常 profile。
- 不会自动合并 temp.1 的独立配置。可在旧版本导出功能可用时导出工作区，或在本版本通过文件菜单导入自己的 Q-Dir 状态文件。
- 首次保存旧会话时升级至 INI v3，并生成 `.before-v3-*.bak`。请勿把新版会话覆盖回旧版配置目录。

## 相对 temp.1 的主要变化

| 部分 | 本包新增或改进 |
| --- | --- |
| QDR 导出 | 文件 → 导出 Q-Dir 状态：保存布局、标签、活动窗格及应用扩展配置；完整列快照可输出原生查看、排序、分组、图标大小与列设置。 |
| QDR 导入 | 补齐本程序六种布局的窗格位置映射与活动窗格；校验 CODEMODE1 数据，损坏视图保留目录与显式模式并警告。修正缺少 LogicalViewMode 导致大图标恢复尺寸错误的问题。 |
| 编辑菜单与工具栏 | 剪切、复制、粘贴、删除、重命名、属性、撤销共用 Shell 命令和可用状态；执行前复查窗格、导航及选区。 |
| 状态栏 | 项目数、选中数、可取得的选中大小、当前目录所在卷容量，以及查看方式入口。未知数据不显示为零，不递归计算文件夹大小。 |
| 导航 | 每标签订阅原生前进/后退状态，改进按钮可用状态；过期导航回调不覆盖新地址和状态。 |
| 目录树 | 视图 → 目录树，默认关闭，偏好独立保存；显示/隐藏保持已有文件视图实例。 |
| 工作区收藏 | 收藏夹内保存当前工作区、追加已保存工作区，复用 QDR 预览、备份与追加流程。 |
| 默认查看 | 工具 → 选项 → 新建标签默认查看，提供八种预设，保存模式及图标大小；不改变现有标签。 |
| 新建文件夹 | 加强创建及延迟重命名的上下文检查，避免切换窗格或导航后作用于过期目标。 |

## 验证与限制

- 本次发布前重新运行 Settings smoke，通过；发布构建与二进制哈希在打包时验证。
- 此前隐藏原生 Shell 检查覆盖导航状态、查看预设及原生视图流恢复；不等同于本发布包的真实窗口验收。
- **Ctrl+鼠标滚轮尚未完成修复验收**，当前包含诊断支持，不能当作已解决。
- **导入后文件区变黑、重启变白仍待复现定位**；跟随系统/浅色/深色选项尚未完成。
- 文件操作后的焦点、正反 Tab、四窗格操作、目录树交互与重启仍待完整 GUI 验收。
- Q-Dir 实际读取本程序导出及再次保存仍待验证，尤其大视图流；不能称为全兼容。没有完整列快照时原生视图字段省略，已知状态仍保存在应用扩展。
- 布局比例目前固定；预览窗格、通用虚拟目录持久化、第三方 Shell 扩展崩溃隔离尚未完成。
- 未启用 Win+E 或系统文件夹默认打开方式接管。

## 建议先看

1. 查看新增编辑菜单、工具栏、状态栏，打开目录树。
2. 导入一份 QDR，再导出一个新文件；核对窗格、标签、排序与分组。
3. 用临时文件复制粘贴和删除，立即按方向键观察焦点；检查 Tab/Shift+Tab。
4. 关闭重开，检查标签、查看方式、排序和分组。反馈注明窗格、操作顺序与实际结果。
