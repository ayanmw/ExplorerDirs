# Explorer Dirs `preview-0.6.0-temp.26`

本版本基于当前源码生成，使用独立 profile；保留 temp.25，不覆盖日常 profile。

## 相较 temp.25 的变化

- Shell 文件命令状态查询期间，如果窗格、导航或选区上下文变化，会放弃整组过期状态读取，避免继续初始化后续原生命令菜单。
- 大目录文件操作后，如果 Shell 项目计数连续四次停在同一旧值，会提前进入已有刷新兜底；计数仍在变化时继续等待，新的 watcher 活动会重新开始观察。

## `.qdr` 虚拟位置兼容范围

- 当前版本支持当前 Windows Shell 可解析且确认是文件夹的绝对解析名称；缺少对应扩展提供程序时，只影响该标签的恢复。这是当前源码已实现并经专项烟测的兼容范围，不列作相较 temp.25 的新增改动。
