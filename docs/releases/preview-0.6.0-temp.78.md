# Explorer Dirs Preview 0.6.0 temp.78

这是当前 `main` 的隔离预览包，程序与配置位于 `app/`，不会覆盖日常 profile。

相较 temp.77，本版包含：

- 标题栏显示模式，可显示当前目录、当前标签或最近打开的收藏夹；
- Shell 列值筛选修复与性能改进，包括属性读取失败时的正确路径、不可变查找集和后台排序；
- Shell 视图刷新期间保留已确认的文件选择，避免异步枚举暂时扩张选区时覆盖用户选择；
- 仅在显式 trace 时收集选择恢复诊断样本；
- `.qdr` 导入中四个窗格树均关闭时，不再错误提示忽略 `TreeNsplit`。

文件夹/磁盘右键入口仍不会自动安装。要验收入口，先使用本目录 `tools/folder-verb.ps1 -Mode Preview` 查看能力和 EXE 哈希；只有确认此预览版的目录参数与 Shell 菜单行为后，才用该哈希显式启用。不要将入口指向源码目录或旧版本。
