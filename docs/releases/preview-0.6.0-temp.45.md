# 临时预览 temp.45

## 本版内容

本版基于 temp.44 当前源码构建。相较 temp.44，状态栏在当前可见标签的 Shell 选区变化后会合并刷新项目数、选中数和可取得的选中项大小；切换标签也会排队刷新。隐藏窗格、导航开始或卸载会取消待处理刷新，避免读取过期视图。此前版本功能继续包含在本包中。

此版本使用包内独立 profile，不会覆盖 temp.44 或日常配置。
