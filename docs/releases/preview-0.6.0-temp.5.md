# 0.6.0 临时预览第五版

日期：2026-10-24。目录版本：`preview-0.6.0-temp.5`；程序集版本：`0.6.0-preview.temp.5`。

本包从当前源码构建，配置位于 `app/profile/`，与日常版及 `src` 调试 profile 分开。它提供近期路线图进展供预览，不表示已完成真实 GUI 或 Q-Dir 互操作验收。旧版本保留，不覆盖。

## 相对 temp.4 的主要变化

- **多窗口会话：**Ctrl+N 创建新窗口，每窗口保存到独立会话 INI；`WindowSessions.ini` 保存启动恢复顺序。无参数的第二次进程启动请求激活现有窗口，目录打开请求继续转发给现有实例。窗口本地固定标签跟随会话；收藏、筛选预设、UI/目录树偏好和布局比例仍由 profile 共享。
- **查看方式与输入：**Ctrl+滚轮按自定义顺序循环八种 Shell 查看方式；Ctrl+Shift+1～8 可直接选择。新标签默认详细信息视图，复制标签继承标签的查看、排序、分组、列和筛选设置。
- **标签快捷操作：**Shift+Enter 在新标签打开当前选中的文件夹；中键和双击标签可关闭标签，保留每个窗格至少一个标签。
- **原生文件操作：**文件视图使用 Windows Shell ExplorerBrowser；保留 Shell 的查看、排序、分组、新建和属性菜单，并在可确认目标时在前面添加本程序命令。Ctrl+A 菜单全选使用 Shell 原生加速键路径；隐藏宿主矩阵覆盖八种查看方式。
- **导航和筛选：**加入原生目录树、Search Folder 搜索以及每标签快速筛选；筛选收藏可保存并跨窗格载入。目录树开关、筛选状态、布局比例、标签会话等通过可移植 INI 保存。
- **Q-Dir 状态交换：**`.qdr` 导入可预览并备份当前会话；导出覆盖已核实的布局编号、窗格、活动窗格、查看状态和本程序扩展数据。Windows Shell 原生读取流和本程序内部状态回归已有隐藏验证，Q-Dir 应用的实际读写仍待验收。
- **状态栏：**显示项目数、选中数、可取得的选择大小及卷容量信息；未知大小不会作为零值显示。

## 隔离与启动

运行 `app/ExplorerDirs.App.exe`，需要 .NET 10 Windows Desktop Runtime。本包的配置保存在本目录的 `app/profile/`；首次运行与后续保存不修改项目根目录的日常 profile。请从本目录启动，不要启动 `src` 下的调试构建，也不要在程序运行期间覆盖包目录。

`app/SHA256.txt` 记录 EXE 和 DLL 的 SHA-256。`app/FolderRoutingCapability.ini` 只描述此构建是否接受单目录启动参数，并不启用 Windows 文件夹关联或 Win+E 接管。

## 已知限制与验收重点

- **未做本包可见 GUI 验收：**本包由 Release 构建和隔离 profile 检查生成，没有启动 GUI、模拟物理输入或操作桌面。隐藏 Shell 宿主与配置 smoke 结果不等同于窗口使用体验。
- **文件操作与自动刷新：**需复测复制、粘贴、删除确认/回收站、重命名、撤销、新建文件夹重命名、列表自然更新，以及命令后的键盘焦点；特别关注多窗格 F2 方向键和 Shift+Delete 确认框返回。
- **右键菜单：**需分别检查选中文件后点空白、文件/文件夹条目、多选和键盘菜单；确认自定义项位于原生菜单前，查看/排序/分组/刷新/新建/属性等 Shell 项仍可用。
- **多窗口：**需检查快速连续 Ctrl+N、窗口独立修改和关闭、重启恢复，以及第二次启动是否激活现有窗口；本包未做可见窗口/跨重启验收。
- **Ctrl+滚轮和焦点：**隐藏宿主已覆盖八种查看方式的 Shell 命令路径；物理滚轮路由、可见效果、排序/分组和普通滚轮行为仍待验收。
- **Q-Dir 互操作：**真实 Q-Dir `.qdr` 导入、导出后由 Q-Dir 读取并保存、再导入对比仍待实测；不据本程序自身往返宣称完整兼容。
- **主题和颜色：**跟随系统/浅色/深色选项尚未交付；导入后文件区颜色变化仍需可见实验。第三方 Shell 扩展运行在应用进程内，尚未实现崩溃隔离。
- **命名空间与系统接管：**当前会话持久化以普通文件系统目录为主；回收站、库、此电脑和网络位置需单独验证。没有启用 Win+E 或默认文件夹打开动作。

请在隔离包中集中预览，反馈具体窗格、步骤、预期和实际结果；后续路线图按反馈调整。
