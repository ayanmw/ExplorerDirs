# 临时预览 temp.37

## 本版内容

- 文件系统目录监视器收到现存文件或文件夹的大小、修改时间、属性等 `Changed` 事件后，按路径去重并等待 250 ms 静默期，再向 Shell 发送 `SHCNE_UPDATEITEM`。
- 每批最多处理 128 个不同路径；批次超限或路径超过 `SHCNF_PATH` 的长度范围时，仍回退到原有整视图刷新。
- 创建、删除、重命名、Watcher 错误和项目数量不匹配继续走原协调/刷新路径。

- App Release 构建通过，0 警告、0 错误。
