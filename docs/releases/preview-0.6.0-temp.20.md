# Explorer Dirs `preview-0.6.0-temp.20`

此版本是基于 `preview-0.6.0-temp.19` 的隔离预览包，包含已验证的环境变量刷新回滚修正，以及当前源码中此前累计的多窗格、标签、Shell 文件视图、目录树宽度和 `.qdr` 导入/导出功能。

## 本版变化

- 如果刷新进程环境变量时，更新中途失败且某个变量回滚也失败，程序会记录未恢复的变量名。下一次刷新会继续尝试清除已从注册表删除、但可能残留在当前进程中的变量。
- 回归用例模拟先写入成功、后续写入失败、回滚失败及下一轮移除计划。Release `SettingsSmoke`、App Release 构建和发布隔离 smoke 通过。
- `.qdr` 中能被本机 Shell 解析且确认为文件夹的绝对 Shell 名称（包括 `::{GUID}`）已由当前实现支持；缺失命名空间提供程序时跳过对应标签并提示。

## 验收边界

- 本包使用 `app/profile/` 独立配置目录，不写入项目日常 profile。
- 没有启动本预览、ExplorerBrowser 或 Q-Dir。GUI 焦点/鼠标流程、目录树拖动与重启恢复、Q-Dir 实际 `.qdr` 互操作、环境变量真实注册表通知流程仍待可见验收。
- 此包验证的是构建和隔离设置，不代表完整 Shell/Q-Dir 兼容或稳定性目标已经完成。
