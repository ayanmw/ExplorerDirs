# Explorer Dirs 0.6.0 临时预览 temp.29

## 本版相较 temp.28

- F4 打开当前标签的最近访问目录列表；选择后在同一标签导航。每标签最多保留 20 个最近目录，复制标签时复制其历史。本历史仅在本次运行期间维护。
- F9、工具菜单及工具栏可按需递归统计当前文件系统目录的总字节、文件数和子目录数；再次触发可取消，导航、切标签或隐藏窗格时取消。统计在后台运行，不跟随重解析点，不自动扫描，也不读取虚拟 Shell 位置。
- 本版仍使用原生 ExplorerBrowser 文件视图。F9 是当前目录汇总，不是 Q-Dir 的逐行文件夹大小/子项计数列。

## 使用

运行 `app/ExplorerDirs.App.exe`。本预览使用隔离 profile；请保留 `app` 目录结构。F4 查看当前标签最近位置，F9 开始或取消当前文件系统目录扫描。

EXE 与 App DLL 校验值以包内 `app/SHA256.txt` 为准。
