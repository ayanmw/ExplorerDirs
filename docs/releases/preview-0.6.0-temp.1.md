# 0.6.0 临时预览：相对 0.5.2 的变化

日期：2026-10-19。版本：`preview-0.6.0-temp.1`。

这是用户要求提前试用的临时包，尚未通过完整 GUI 验收；0.5.2 保留为日常版。比较基线为记录发布 0.5.2 的提交 `4a6aca9`，本包包含其后的功能以及本轮焦点候选修复。

## 启动与配置

- 在本版本目录进入 `app`，双击 `ExplorerDirs.App.exe`。
- 配置在本版本的 `app/profile/`，首次打包复制当前日常版的四类 INI（存在的文件）。此后两份配置独立，不会修改项目根目录的 `profile/`，也不会影响 0.5.2 的会话。
- 新版会话升级为 INI v2，升级前在本包 profile 中生成 `.before-v2-*.bak`。不要把 v2 会话直接覆盖回 0.5.2；回到旧版时直接启动旧版 EXE 即可。
- 需要已安装 .NET 10 Windows Desktop Runtime。临时包不依赖 `src` 的编译输出。

## 最值得预览的变化

| 功能 | 相比 0.5.2 的变化 / 入口 |
| --- | --- |
| Q-Dir 配置导入 | **文件 → 导入 Q-Dir 配置 (.qdr)…**；先预览数量和不支持项，再备份当前会话、按窗格追加。支持目录、标签顺序、已确认的布局与查看方式；已识别的格式还可导入排序、分组、图标大小、列顺序和列宽。 |
| 标签栏 | 单行溢出滚动、同窗格拖动排序、固定/取消固定标签；固定标签避免被快捷关闭。Ctrl+1～9 按显示顺序切换。 |
| 视图设置 | **视图 → 当前标签查看方式**及 Ctrl+Shift+1～8；每标签独立保存显示列、列宽和列顺序，复制标签复制快照。 |
| 路径导航 | 可点击面包屑；Alt+D / Ctrl+L / F4 进入完整路径编辑，Esc 返回。 |
| 搜索 | F3 / Ctrl+E / Ctrl+F 打开当前窗格搜索栏；使用原生 Shell 搜索结果，关闭搜索回到目录。 |
| 收藏与外观 | 顶部收藏夹菜单；**视图 → 紧凑布局**，收紧工具栏、标签和窗格间距。 |
| 会话与历史 | 保存活动窗格及各窗格选中标签；切换标签/布局时保留 Shell 视图对象，减少历史被重建的风险。 |
| 键盘与新建目录 | F6 / Shift+F6 切换主要焦点区域；新建文件夹增加菜单/工具栏入口，避免依赖可能被其他应用占用的 Ctrl+Shift+N。 |

## 可靠性方面的改动

- 区分鼠标右键背景和条目目标，限制自定义菜单命令来源；多选焦点恢复不再任意跳到第一个选中项。
- 不可访问/离线路径仍可保留；目录预检在后台进行，新建文件夹不再同步遍历全部子目录。
- INI 损坏备份、高版本保护、并发/外部修改检测；可读标签尽量恢复，隐藏标签使用缓存减少定时 Shell 查询。
- 环境刷新读取最新用户/机器变量，展开引用、合并 PATH，失败时回滚；打开命令行改为后台启动。
- 增加异常退出标记、脱敏日志及只读诊断工具；不代表已实现原生 Shell 扩展的进程隔离。
- 支持目录参数与同配置实例转交；**没有接管 Win+E、文件夹默认打开方式或系统 Shell**。

## 本轮验证及已知问题

- Release 构建和 Settings smoke 通过。两份本机 `.qdr` 只读解析分别识别 42/28 个标签，存在视图数据的 42/24 个标签均能读取；不代表所有 Q-Dir 版本通用兼容。
- 2026-10-19 隔离 GUI 验证：旧候选构建 Ctrl+C/V 产生副本后，直接按上箭头可以选择相邻文件。
- 同一测试发现：左上窗格 Shift+Delete → Enter 后焦点跑到右下窗格。跟踪记录显示 Shell 对话框把焦点交给另一窗格的 `Static` 容器，被宿主误认为窗格切换。本包已限制为真实文件内容窗口取得焦点时才据此激活窗格；**候选修复已编译，修复后的 GUI 复测尚未完成**。
- 本包已移除本轮临时强制焦点日志。精确发布二进制尚未做 GUI 启动/操作验收；不把之前隔离副本的结果当成本包验收。
- `.qdr` 选择/确认追加、正反 Tab 全循环、搜索、列调整后重启、拖放和第三方扩展仍待完整验收。树视图、预览、通用虚拟目录保存和扩展崩溃隔离尚未完成。

## 建议试用顺序

1. 看标签拖动/固定、面包屑、紧凑布局是否顺手。
2. 导入一份 `.qdr`，检查窗格、标签顺序和视图设置；旧标签会保留并追加新标签。
3. 用临时文件试复制粘贴及确认删除，重点观察焦点是否留在原窗格。
4. 关闭重开，检查标签、排序、分组、列宽和活动窗格。

反馈时注明窗格、按键顺序、期望与实际结果。新版试用反馈后再调整路线图；未验证项不标为完成。
