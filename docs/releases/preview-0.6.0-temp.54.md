# Explorer Dirs 0.6.0 临时预览版 54

本版包含 F9 递归目录统计的状态栏进度反馈，以及 F10 打开应用菜单栏的快捷键接线。该包用于预览，不代表 GUI 验收通过。

## 本版重点

- F9 递归扫描每检查 256 个项目产生进度样本，状态栏更新最多每 250 ms 一次；最终仍显示文件数、子目录数和总大小。不会自动扫描目录；再次按 F9 可取消。
- 无修饰 F10 打开主菜单栏的“文件”菜单；Alt+F10 不由应用拦截。
- 启用隔离焦点 trace 时，F2 重命名方向键路由记录会包括发送目标和发送后的焦点 HWND，用于定位多窗格重命名问题。
