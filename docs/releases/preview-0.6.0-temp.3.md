## 运行

运行 `app/ExplorerDirs.App.exe`，需要 .NET 10 Windows Desktop Runtime。
使用本包 `app/profile/` 独立配置，不覆盖日常配置或 temp.2 配置。初始配置来自项目日常 profile；不会自动合并 temp.2 运行期间的修改。
