# 0.6.0 临时预览第六版

日期：2026-10-24。目录版本：`preview-0.6.0-temp.6`；程序集版本：`0.6.0-preview.temp.6`。

本包从当前源码生成，配置位于 `app/profile/`，与项目日常配置和 `src` 调试 profile 隔离。该版本提供路线图中的近期功能进展供预览；没有启动 GUI，也没有完成真实窗口或 Q-Dir 互操作验收。旧预览包保留，不覆盖。

## 相对 temp.5 的主要变化

- **当前视图导出：**活动文件视图可导出 CSV、UTF-8 制表符 TXT、HTML 和 BIFF8 XLS，使用 Shell 当前可见列与行顺序；即使存在选中项，也导出整份可见视图。快速筛选和分组组合已有隐藏生产宿主检查。
- **当前视图打印：**按 Shell 查看方式生成缩略图网格、列表、平铺或详细表格；隐藏 HostProbe 检查了 Shell 图像、行数和文档布局，没有打开打印对话框或提交打印任务。
- **原生窗格状态：**会话 v8 为每个标签保存详情窗格显示状态，并与预览窗格保持互斥；预览/详情面板状态切换已有隐藏宿主检查，可见 Preview Handler 内容仍待验收。
- **Shell 虚拟位置：**会话及 `.qdr` 导入/导出加入此电脑、回收站、库、桌面文本身份；ZIP 路径由 Windows Shell 检查文件夹属性。虚拟位置不再冒用旧文件夹的容量和目录树状态。
- **路径边界：**包含 `.zip` 的名称需满足完整路径组件条件；真实存在的 `.zip` 后缀目录仍保留为普通文件系统路径。

## 隔离与启动

运行 `app/ExplorerDirs.App.exe`，需要 .NET 10 Windows Desktop Runtime。配置保存在 `app/profile/`，不会隐式写回项目根目录日常 profile。请从本目录启动，不要运行 `src` 下的调试构建，也不要在应用运行时覆盖包目录。包内 `app/SHA256.txt` 记录 EXE 与 DLL 校验值。

## 验证边界与待验收项

- Release SettingsSmoke、App 与 NativeProbe 构建通过；这不等同于真实窗口体验验收。
- 本轮未启动应用窗口、未模拟键鼠、未操作桌面。虚拟 Shell 导航/重启恢复、ZIP provider 行为、菜单与工具栏、焦点遍历、Ctrl+滚轮物理输入、打印预览和 Q-Dir 实际读写均待可见验收。
- 复制、粘贴、删除确认与回收站、撤销、重命名、自动刷新和多窗格焦点仍需在隔离测试文件上复测。
- 自动刷新在大目录和网络/离线位置的响应仍有未关闭的性能问题；没有据隐藏压力测试宣称完全解决。
- 导入后文件区颜色变化仍需可见复现。主题个性化和系统接管未在此包中完成。
- 第三方 Shell 扩展仍在应用进程内执行，尚无崩溃隔离。
