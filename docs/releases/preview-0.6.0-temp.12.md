# Explorer Dirs 0.6.0 临时预览第十二版

日期：2026-10-24。目录版本：`preview-0.6.0-temp.12`；程序集版本：`0.6.0-preview.temp.12`。

此预览从当前源码构建，程序位于 `app/`，使用独立的 `profile/`，不会升级日常使用的配置。它不依赖 `src/` 下的调试输出。没有启动 App、ExplorerBrowser、Q-Dir 或任何可见 GUI；请只在测试目录预览，Shell/Q-Dir 实际行为仍需验收。

## temp.11 之后的变化

- `.qdr` 位置导入和会话现在接受本机 Shell 可解析、并确认具有 `SFGAO_FOLDER` 的绝对 Shell 解析名称，包括 `::{GUID}` 与 `shell:::{GUID}`。导出保留 Shell 位置文本；缺少提供程序或目标不再是文件夹时，对应标签可能无法恢复。协议 URI、非文件夹及搜索结果 PIDL 不在支持范围内。
- 非内置 Shell 位置的标签和面包屑使用 Windows Shell 友好名称，不再直接显示 `::{GUID}`。
- 新建文件夹的自动重命名会等待原生重命名编辑框真正取得焦点；Shell 接受编辑请求后不重复发送请求。
- 状态栏磁盘容量显示可用比例与可用字节；总量为 0 或容量不可用时不显示虚构比例。
- Tab/Shift+Tab 的动态焦点顺序包含可见搜索/快速筛选控件、标签、目录树、详细信息列标题、文件视图和查看方式入口；原生控件的实际焦点顺序尚未 GUI 验收。

## 包含的功能

- 多窗格、多标签、十二种布局、每窗口独立会话及便携 INI 配置。
- 原生 ExplorerBrowser 文件视图、文件/文件夹图标、查看/排序/分组、原生右键菜单和文件操作。
- `.qdr` 布局/标签导入导出、每标签查看状态、搜索与快速筛选、目录树、收藏夹/工作区。
- 当前视图 CSV/TXT/HTML/XLS 导出与打印、状态栏项目/选中/容量信息、预览及详情窗格开关。

## 验证及限制

- 发布脚本会构建本目录版本并写入 EXE/DLL SHA-256 清单；隔离发布脚本 smoke 通过，确认 profile 文件复制及已存在版本拒绝覆盖。
- 全量 SettingsSmoke 通过；App Release 构建通过，0 警告、0 错误。
- 没有启动本包、ExplorerBrowser、HostProbe、NativeProbe 或 Q-Dir。Shell 虚拟位置的可见导航、真实重命名编辑、键盘焦点、状态栏窄窗格布局、Q-Dir 实际读取/保存、打印与预览渲染仍待桌面验收。
- 自动刷新 P0、超大/慢速/网络目录响应、颜色过滤、主题个性化及第三方 Shell 扩展故障隔离仍未完成。

从 `app/ExplorerDirs.App.exe` 启动，并只在测试目录中预览。运行需要 .NET 10 Windows Desktop Runtime。本包是未完成 GUI 验收的临时预览，不代表已通过完整 Explorer 或 Q-Dir 兼容验收。
