# 0.6.0 临时预览第四版

日期：2026-10-24。目录版本：`preview-0.6.0-temp.4`；程序集版本：`0.6.0-preview.temp.4`。

本包从当前源码重新构建，使用 `app/profile/` 独立配置，不覆盖日常配置、源码调试配置或旧临时版。它用于继续预览 0.5.2 之后的功能进展；尚未完成全量 GUI 验收，重点限制见下文。

## 相对 temp.3 的主要变化

- **Q-Dir 布局与分隔比例：**现在有 12 种布局，包括三列、三行、四列、四行、左双右大、上双下大等；分隔条可拖动，布局比例独立保存，四窗格允许上下两排设置不同宽度。
- **Q-Dir 状态交换：**可导入和导出 `.qdr`，保留标签、布局、查看/排序/分组、列状态、活动窗格、固定标签及本程序扩展配置；增加工作区 `.qdr` 收藏与导入前备份。字段和原生读取探针已覆盖；实际用 Q-Dir 打开本程序导出文件并再次保存仍待验证。
- **文件视图与状态信息：**增加全选/取消/反向选择入口；状态栏补充总项目数、选中数、可取得的选择大小、卷容量和查看方式入口。
- **导航与工作区：**增加顶部目录收藏、当前目录搜索入口及搜索结果返回路径保护；新增布局比例、目录树和工作区配置的隔离保存。真实窗口行为仍需验收。
- **新建文件夹：**菜单、工具栏和快捷命令统一走 Shell 操作及状态查询，延迟重命名增加上下文检查。
- **目录自动更新：**增加本地固定磁盘目录的事件监视和有界刷新兜底，刷新后尝试保留选区与焦点。自然漏更场景尚未稳定复现，不能把自动刷新问题视为完全解决。
- **发布配置：**发布目录版本会映射到程序集版本，并由隔离 fixture smoke 覆盖；该包的 exe/dll SHA-256 写在 `app/SHA256.txt`。

## 启动与配置

运行 `app/ExplorerDirs.App.exe`，需要 .NET 10 Windows Desktop Runtime。此包使用打包时复制的 `app/profile/`；首次运行与保存只影响本包。它不会自动合并 temp.3 运行期间产生的改动。请从本目录启动，不要启动 `src` 下的调试构建，也不要在程序运行时覆盖包目录。

## 已知限制与验收重点

- **自动刷新仍属待验收项：**隐藏宿主创建/删除和 3,000 项压力测试通过，但自然 Shell 漏更与 fallback 重试边界仍未完整证明；如列表不更新，可用 F5 并记录操作、窗格和耗时。
- **当前目录搜索需重点复测：**源码修正有隐藏宿主验证，尚未对本包真实窗口完成搜索、结果显示、Esc/返回、标签切换和重启验收。
- **Ctrl+鼠标滚轮未做真实输入验收：**隐藏测试确认 Shell 子视图能调整当前查看方式的尺寸，未确认真实滚轮是否路由到视图；目前证据显示 mode 不会随滚轮循环。
- **多窗格 F2 方向键未做可见复测：**候选修正已在源码，需验证编辑框文字光标/选区、文件选区和活动窗格。
- **主题与文件区颜色仍未完成：**跟随系统/浅色/深色方案未交付；导入后文件列表区域变黑、重启白底的现象仍待真实窗口定位。
- **Q-Dir 互操作未完成：**本程序导入/导出格式和原生流有隔离测试，Q-Dir GUI 读取、保存、再次导入仍待验收。
- 文件操作、右键菜单、状态栏、四/十二布局拖动、分隔比例重启、跨窗格焦点、网络目录及第三方 Shell 扩展影响仍需真实窗口测试。
- 没有启用 Win+E、默认文件夹打开或其他系统接管入口。
