# 系统入口集中验收清单

本清单用于后续一次性可见验收，不代表目前已经通过。项目规则要求本阶段不操作桌面；程序窗口、系统 Explorer 和当前用户的注册表均未被本清单创建或修改。

## 标签菜单：在系统 Explorer 中浏览

使用独立测试副本与测试 profile，不使用日常会话。

1. 在普通本地目录标签上打开标签标题右键菜单，确认“使用 Explorer 浏览”位于菜单第一项。
2. 执行该命令，确认 Windows Explorer 打开当前标签的准确路径；Explorer Dirs 当前窗格、标签、选区和焦点不被关闭或重置。
3. 在标签栏空白处右键，确认弹出当前标签的同一菜单，并可作用于右键时的当前标签。
4. 双击标签栏空白处仍新建默认详细列表标签；中键点击标签仍只关闭该标签。
5. 对此电脑等 Shell 虚拟文件夹重复第 1、2 步，记录 Windows Explorer 是否能解析该位置；若不能，保留 Explorer Dirs 状态并记录 Shell 的实际结果。

## 用户级文件夹入口：只读预览与启停

入口启停会写入/删除当前 Windows 用户的 `HKCU\Software\Classes\Directory\shell` 与 `Drive\shell` 项。不得在日常用户配置上做启停测试；使用可丢弃的 Windows 测试用户或等价的隔离注册表配置，并在结束时检查清理结果。

1. 打开“工具 → 文件夹入口”，只执行状态读取与预览。核对目标 EXE 路径、SHA-256、目录参数能力声明，以及目录/驱动器两处现状。
2. 确认与预览目标不一致时启用按钮不可用；存在不属于本程序或被外部改写的冲突项时，不覆盖、不删除。
3. 在隔离用户中启用后，分别从普通文件夹与固定磁盘右键调用入口，确认打开 Explorer Dirs 并导航到准确位置。
4. 禁用后只移除仍完整匹配本程序所有权标记的入口；确认外部修改项保留，测试用户中的两处自有项消失。
5. 关闭测试副本后再复核隔离用户注册项状态；不以隐藏脚本 smoke 代替真实 Shell 菜单结果。

## 验收记录

逐项记录：通过 / 失败 / 未测、测试副本 BuildIdentity、Windows 版本、普通目录或虚拟位置、入口状态变化和可见结果。若没有隔离 Windows 用户，标签菜单可单独验收，文件夹入口只读预览可单独验收；不要为了完成清单而改动日常 `HKCU`。
