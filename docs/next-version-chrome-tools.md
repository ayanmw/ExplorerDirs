# temp.86 后续版：窗口小工具与顶部布局整理

2026-11-03 用户要求加入下个版本。本文记录待实施范围，不代表已实现或已验收；不加入当前 temp.86 收尾和发布门槛。后续版本编号在发布时确定。

2026-11-04 另新增文件哈希和文件系统链接工具规划，见 [next-version-file-tools.md](next-version-file-tools.md)，同样不在 temp.86 实施。

## 独立放大镜按钮

- 在顶部窗口工具区提供独立图标按钮、中文提示和可访问名称。
- 复用 WindowsMagnifierLauncher.Open，与已有“工具 → 屏幕放大镜”和 Alt+L 使用同一路径；不再实现一套放大镜。
- 按钮异常提示沿用现有入口；按钮不是切换放大镜开关，不替用户关闭已开启的放大镜。

## 临时缩小到系统托盘

- 独立按钮，名称“缩小到系统托盘”。普通最小化、关闭行为保持原样。
- 只作用于当前窗口，不隐藏其他窗口；隐藏时从任务栏移除并显示一个对应的托盘图标。
- 创建托盘图标成功后才隐藏窗口；创建失败保留窗口并反馈错误，避免出现无法恢复的隐藏窗口。
- 双击托盘图标：恢复同一个窗口及其原显示状态（普通或最大化）、显示器位置和大小，再移除该托盘图标。
- 恢复沿用应用焦点恢复路径，使用户可继续操作原文件视图，不新建窗口或重新打开全部标签。
- 托盘图标和订阅属于窗口生命周期；窗口真正关闭或应用退出时释放。
- Explorer/任务栏重启后，仍隐藏的窗口须重新提供恢复入口；已恢复的窗口不能重新出现残留图标。
- 不将隐藏状态作为下次启动的默认状态，不增加常驻托盘、关闭即隐藏或全局快捷键等未请求的行为。

## 菜单、布局快捷按钮与对齐

- 参考用户提供的 Q-Dir 截图，菜单保留在左侧；布局快捷按钮分组靠右，放大镜和托盘按钮为独立窗口工具，不混入文件编辑命令。
- 保留全部既有布局及菜单入口；窄窗口下通过布局菜单保留可达性，不把菜单文字挤到不可用，也不改变当前窗格与布局比例。
- 先复用现有主题图标与语义颜色；不扩展为标题栏重写或新主题框架。
- 统一主工具栏和窗格导航栏的按钮尺寸、内边距、图标垂直居中及相邻间距；兼容既有紧凑模式和 Windows DPI 缩放。
- 尊重已确认的工具栏范围：剪切、复制、粘贴、删除、重命名、撤销、重做继续位于编辑菜单与原生快捷键中。
- 保持最新标签栏约定：顶部 3 DIP 选中线、右侧并排溢出箭头、无标签行新建/关闭按钮，不借布局整理恢复已删除控件。

## 实施顺序与验证

1. temp.86 完成并发布后，再实施本批。先接复用现有入口的放大镜按钮。
2. 实现当前窗口的托盘生命周期，覆盖失败、恢复和 Explorer 重启。
3. 调整菜单/右侧布局组与工具栏对齐，并回归所有布局命令。
4. 后台检查命令接线和状态转换；集中可见检查单/多窗口、最大化、双屏、DPI、深浅主题、窄宽窗口和键盘焦点。
5. 验证托盘恢复后无残留图标，关闭后无残留订阅；隐藏/恢复不重建 Shell 视图，不声称能减少进程内存。

需在实施前审阅实际布局草图；本次仅按用户要求纳入后续版本规划，未改变运行时行为。
