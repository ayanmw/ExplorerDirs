## 原生字段证据

目标为本机 Q-Dir 12.79，SHA-256 与[布局映射](qdr-layout-mapping.md)一致。
REA `open_binary` 确认 x86_64 PE 身份；`read_bytes` 因缺少已配置的深度分析后端不可用。
没有安装后端。以下字段通过普通 PowerShell 只读 PE 节映射和已有反汇编核对，不能称为 REA 深度分析输出。

- ASCII `SP0`/`SP1`/`SP2` 位于 VA `0x52e1c8`/`0x52e1c4`/`0x52e1c0`；`0x52e1bc` 为树字段 `SPT`，不混用。
- `0x46d182～0x46d234` 读取三个字段，默认 5000，依次存入对象 `+0x7b20/+0x7bc8/+0x7c70`，即根和两个子分隔器的 `+0x48`。原生接受 1～10000，其余值恢复 5000。
- `0x45d449～0x45d57b` 根据分隔方向取得可用宽/高，减去分隔条空间，以第一侧长度乘 10000 再除以可分空间，经 `MulDiv` 写入上述位置。
- UTF-16 格式串 `0x52d8a0` 前三个字段是 `SP0=%d`、`SP1=%d`、`SP2=%d`；`0x45d58a～0x45d642` 的参数装配保持该顺序。
- 本地现有 `start.qdr` 只读字段为 6479/4978/5002。没有改动该文件，也没有把其中的工作路径记录进本项目。

这证明万分制嵌套分隔比例，未证明跨程序的边框、最小尺寸或像素舍入完全一致。

## 转换规则

令 `r=SP0/10000`、`a=SP1/10000`、`b=SP2/10000`。

| 应用布局 | 使用的比例 |
| --- | --- |
| 单窗格 | 无可见分隔线 |
| 左右双 | 左宽比例 a |
| 上下双 | 上高比例 r |
| 四宫格 | 上高 r；上排左宽 a，下排左宽 b |
| 左大右双 / 上大下双 | 主分隔 r；第二子分隔 b |
| 左双右大 / 上双下大 | 主分隔 r；第一子分隔 a |
| 三列 / 三行 | 顺序权重 r×a、r×(1−a)、1−r |
| 四列 / 四行 | 顺序权重 r×a、r×(1−a)、(1−r)×b、(1−r)×(1−b) |

导出使用反向公式。字段四舍五入至万分之一，极小/极大正比例限制在 1～9999，
防止输出零宽窗格；完整精度仍在本程序扩展中。条带权重表达名义份额，
不包含 Q-Dir 嵌套分隔条的像素宽度，所以不承诺其像素位置完全相同。

## 明确限制与失败处理

- 四宫格现在支持独立上下两排左右比例；a、b 分别保留。共享上高比例 r，原有无下排字段的配置继承上排比例。真实 Q-Dir/应用窗口几何仍待验收。
- 不导入零宽布局。0、10000、越界、非整数和溢出字段使比例恢复被跳过；不丢弃可读标签。
- 没有 SP 字段的旧文件不改变本地比例；部分 SP 字段缺少时，沿用原生默认 5000。未知布局不应用比例。
- 不处理树、预览、窗口位置及 SPT。

## 本程序扩展与接线

当未导出目录树宽度时，带比例的旧扩展格式为 `ExplorerDirs.FormatVersion=2`，含独立四宫格下排字段时为 v3。当前主程序导出使用 v4，并在 `Proportions` 字典与可选 `BottomHorizontal` 之外保存五路目录树宽度。字典
保存全部已记忆布局并保证包含当前布局；可选 `BottomHorizontal` 仅允许布局4，缺失继承 `Horizontal`。旧 v1～v3 扩展继续读取，
高版本、缺失当前布局、错误权重或版本错标会拒绝扩展并回退可识别基础字段。
会话 INI 仍为 v5；比例 INI 升至 v4，读取 v1～v4，升级前保留 `.before-v4-*.bak` 原文。
含下排字段却标记为扩展 v2 的文件拒绝扩展并回退基础字段；不静默丢弃其下排比例。

SP0/SP1/SP2 加入 BaseHash。修改原生比例，或给以前没有比例的导出补写 SP 字段，
均使旧扩展失效，防止旧扩展遮盖外部更改。

导出、工作区收藏、导入前 `.bak.qdr` 备份均包含比例。导入预览说明将恢复多少种布局比例；
确认并备份后，标签沿既有追加方式导入，比例合并保存经过原配置的外部修改/新格式保护，
成功后才更新内存。其他未导入的布局比例保留。当前布局编号相同时也重新排版；
导入中途失败仍按既有方式报告可能已部分追加，不宣称多文件事务或自动回滚。
