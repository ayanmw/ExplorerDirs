## 建议顺序

### 1. 启动、布局与标签

- 从上述 EXE 启动，确认窗口能正常打开、目录图标和文件图标可见。
- 切换四窗格及其他常用布局，再切回四窗格；确认窗格内容和各自标签仍在。
- 在不同窗格新建、复制、关闭标签；分别用中键和双击关闭标签，并检查活动标签。
- 用 `Ctrl+N` 打开另一个应用窗口；分别导航并关闭其中一个，检查另一个窗口仍保持自己的目录和标签。

### 2. 文件区菜单与查看方式

- 先单击选中一个文件，再在文件列表空白处右键。确认菜单按空白背景操作，不能把命令目标误指向残留选中项。
- 分别在文件、文件夹上右键；再用 `Shift+F10` 或菜单键打开菜单。检查自定义的标签/复制路径操作位于原生 Explorer 菜单前方，原生查看、排序、分组、新建、属性等选项仍可用。
- 用工具栏和 `Ctrl+鼠标滚轮` 切换查看方式；切换排序、分组后确认条目和选区正常。

### 3. 键盘焦点与文件操作

- 在四窗格中用 `Tab` 与 `Shift+Tab` 完整遍历。记录导航控件、地址栏、标签标题、详细视图列标题和文件项的顺序，以及反向遍历是否逐项返回。
- 在多个窗格分别按 `F2`，再按方向键。确认方向键移动重命名编辑光标，不取消编辑或转而移动文件选择；按 `Enter` 完成测试文件重命名。
- 在测试目录内执行 `Ctrl+C`、`Ctrl+V`，粘贴后立即使用方向键；确认焦点和选中项可操作。
- 对测试文件尝试 `Shift+Delete` 并检查确认框、取消/确认后的焦点与视图更新；可再验证 Shell 撤销。不要对其他文件执行删除。

### 4. 实时刷新与状态

- 在活动目录内通过另一个窗口复制、创建、删除测试项目，确认列表不用按 `F5` 即可更新。
- 修改测试文件内容后，检查大小、修改时间等列是否刷新；检查四窗格数量和状态栏项目数。
- 在测试文件夹打开预览/详情窗格，确认窗格切换不会丢失当前路径、视图、选区或焦点。

### 5. 重启与配置

- 退出应用后重新启动，确认布局、窗格目录、标签、排序/分组和每标签查看方式恢复。
- 如果测试 `.qdr`，只对测试配置执行导入/导出，并确认预览、备份和标签追加结果；本清单不把应用自我往返当成 Q-Dir 已兼容的证明。
