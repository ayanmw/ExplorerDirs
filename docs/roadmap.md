## 可复现验收样例

1. 在四窗格各开 3 个标签；切换单窗格再切回四窗格；所有路径仍在；关闭重开后布局与路径恢复。
1. 在任意标签上右键复制标签、关闭其他标签、恢复关闭标签；顶部菜单与快捷布局图标执行相同布局切换，隐藏窗格的标签保持不变。
1. 浏览目录时文件夹与常见文件扩展名显示不同的 Windows Shell 类型图标；右键目录可在新标签打开。
2. 保持程序运行，新建用户变量 `EXPLORER_DIRS_SMOKE=updated` 并触发环境变更通知；打开内置命令行执行 `echo %EXPLORER_DIRS_SMOKE%`，应输出 `updated`。验收后删除此测试变量。
3. 浏览不可读或刚被删除的目录，窗格显示错误；其他窗格和标签仍能工作。
