# temp.86 全局混合排序及列标题闪烁修订（2026-11-05）

## 改动

- 混合排序改为同一profile的全局选项，默认关闭，单独保存Sorting.ini。所有窗口、窗格及标签共用；新建/复制/恢复标签服从该值。旧会话MixedSizeSort字段保留格式兼容，不再覆盖全局偏好。排序列、方向、查看方式仍由各标签独立记忆。
- 同一进程窗口共用配置对象；独立配置实例通过文件监视接收变更。新视图直接使用全局策略首次绑定，不再在刚显示后补做一次相同排序；已加载/隐藏视图按就绪状态应用。
- Name/Size列标题排序期间保留上一帧，行数稳定后释放，最长1500ms；非标题输入、导航和销毁会释放。此过程不调用Refresh，不反向排序、不重新导航。
- Shell晚创建的原生子窗口现在也安装既有观察器，补齐列标题创建时序遗漏。区分原生排序setter消息与真实输入，旧策略应用遇到新用户输入后不再覆盖新操作；原生setter期间不重入读取视图。
- 排序期间阻止空中间状态擦背景和提前打开重绘；释放时只重绘仍属于当前代的视图，避免旧任务重绘新页面。
- 发布配置清单包含Sorting.ini，避免隔离复制预览时丢失全局选项。

## 本轮集中验收

1. 查看“工具→选项→文件夹→混合排序”，切换后检查四窗格与已有标签，再新建/复制标签、重启；菜单勾选不应随当前窗格变化。同一profile的新窗口也应同步。没有新全局配置时默认关闭，不迁就某个旧标签值。
2. Name、Size各连续点击6次，等待和移动鼠标后不应再自行循环排序；重点观察是否还出现整块黑底/白底的一闪。选择一个文件后重复，检查选区及上下方向键焦点。
3. 关闭文件夹大小，对比两种混合状态的Size，应保持原生Explorer效果；开启后确认混合/分类区别。名称、日期、类型仍按各标签当前排序列及方向工作。
4. 排序后立即切标签、切目录、关闭窗口，确认没有冻结、残影或旧画面覆盖新页面。排序遇到新键鼠操作会提前释放，避免长期显示过时内容。
