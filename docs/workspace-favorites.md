## 交互与存储

- “收藏夹 → 保存当前工作区…”打开保存对话框，默认目录为当前配置旁的 `Workspaces`，
  用户指定名称；使用现有覆盖确认、完整快照和写入冲突检查。
- “收藏夹 → 追加已保存工作区”按文件名展示该目录的 `.qdr` 文件。
  点击后重新读取文件，经过导入预览和备份再追加，不将收藏列表缓存当成文件内容。
- 保存到其他位置仍是正常 `.qdr` 导出，但不会自动加入此菜单，完成提示明确区分。
- 不添加另一套状态格式或注册表设置。旧版不会因保存当前会话而删除这些文件。
  原有 `Favorites.ini` 继续只保存单个目录收藏。
- 菜单列表后台枚举，最多展示 200 项，不递归子目录；超过上限提示使用文件菜单导入。
  不在菜单展开时解析所有 `.qdr`。本地文件的修改、重命名和删除在下次展开时重新读取。
- 追加语义与现有导入相同；不隐式关闭当前标签。文件被删除、损坏或外部修改时沿用导入错误反馈。

构建不等于实际菜单、对话框或 Shell 恢复验收；真实保存、取消、覆盖、
追加和重启恢复仍需桌面独占交接后测试。
