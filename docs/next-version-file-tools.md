# 后续版本：哈希与文件系统链接工具

2026-11-04 用户新增规划。本版本 temp.86 不实施，不加入其发布门槛。

## 文件哈希

- 在本应用的文件右键菜单和属性界面提供计算、复制、校验哈希；具体首批算法在实施时确定。
- 优先考虑平台自带算法实现，或可合法随便携包分发的免费/开源 DLL；不依赖用户另行安装工具。
- 大文件后台流式读取，支持进度与取消；文件被修改时不把结果当作稳定文件校验值。
- 首选仅应用内生效；若必须使用全局 Shell 扩展，提供独立、明确、可撤销的安装入口，不自动注册。

## hardlink、junction 与符号链接

- 参考 Link Shell Extension 的选择链接源、到目标位置创建链接及属性查看流程：
  https://schinagl.priv.at/nt/hardlinkshellext/hardlinkshellext.html
- 支持文件 hardlink、目录 junction，以及文件/目录符号链接；目录不称作或实现成 NTFS hardlink。
- 应用内右键入口与属性查看优先，显示类型、目标和失效状态；尽量随便携包使用。
- 实施时验证卷/文件系统约束、权限、相对目标、重名、断链，以及删除链接时不误删目标内容。
- 用户接受必要时做成资源管理器也能使用的全局组件，但安装/注册仍须显式选择，并支持卸载和移动便携目录后的处理。
- 不将 LSE 的克隆、Smart Copy、备份模式等全部功能自动纳入首版。

当前只记录需求和边界，未安装第三方组件、注册扩展或增加运行时入口。
