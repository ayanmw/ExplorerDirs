# 文件夹选项与大小混合排序

用户已确认范围见 temp86-goals.md，按持续开发授权实施，不使用 worktree。

目标：文件夹相关设置集中在工具/选项/文件夹；混合大小排序默认关闭。关闭时文件夹在前、文件在后，各自按大小升降序；开启才统一比较。每标签保存、复制继承及 INI 恢复。其他列不改变。文件区右键仍为原生菜单。

1. 原生能力验证：大小列用 SHCOLSTATE_NOSORTBYFOLDERNESS 让 provider 负责分类；通过每个 folder 实例的私有 COM 能力控制混合设置，不能用全局变量让同路径标签串用。验证 Shell 对降序的反转，并在跨类型比较中补偿当前大小列方向。先用实际私有 Desktop ExplorerBrowser 检查两种模式的完整四行顺序。
2. 标签状态：扩展 ViewState，采集原生状态时保留应用策略；INI 版本兼容、复制/关闭重开及 QDR 扩展往返均需覆盖。缺省 false。拒绝未来配置覆盖的保护不变。
3. 宿主接线：新视图在排序恢复前配置 native folder；切换设置只重排大小列，不完整刷新或重设模式/列。菜单构建和原生命令前后检查导航代际。非本 provider 的位置保留策略供回到受支持视图使用。
4. 菜单：显示文件夹大小、来源及混合排序集中为文件夹组；混合项反映当前标签，切换活动窗格/标签后同步。
5. 验证：原生两模式升降序、两实例同路径独立、文件/文件夹数字次序、选区焦点；默认/复制/INI/QDR；后台总检；可见鼠标列头和 DPI 留集中验收。未完成整批前不覆盖 temp.86。

参考：https://learn.microsoft.com/windows/win32/api/shtypes/ne-shtypes-shcolstate
