# 新建标签使用当前文件夹

## 行为

- “标签页”菜单提供“新建标签时使用当前文件夹”开关，默认关闭。
- 关闭时普通新建标签继续从用户文件夹开始；开启时从该窗格当前活动标签的目录开始。
- 该选项保存到 profile 下的 `NewTabLocation.ini`。
- 复制标签、显式在新标签打开指定目录、恢复会话与导入标签继续使用各自明确的目录。

## 验收边界

- SettingsSmoke 检查默认值、便携 INI 往返及菜单/Pane 接线。
- Release SettingsSmoke 与 App Release build 通过。
- 本批不操作 GUI；真实菜单切换、重启后状态和路径导航需可见验收。
