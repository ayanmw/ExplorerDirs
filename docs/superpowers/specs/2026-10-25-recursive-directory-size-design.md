# 当前目录递归大小设计

## 意图

补上 Q-Dir 可按 F9 查看当前目录递归总大小的常用能力，并让用户能在不导航、不等待目录打开的情况下主动请求。Q-Dir 官方说明同时提到递归文件/子目录统计、大小列显示和避免排序时自动计算的性能取舍；本项目继续使用 ExplorerBrowser 原生文件视图，因此结果先放在独立状态栏区域，不伪装成 Shell“大小”或“类型”列。

## 行为

- F9 对活动窗格当前文件系统目录启动一次递归扫描；再次按 F9 取消。按用户确认的触发方式，仅显式扫描，不因导航或切换目录自动启动。
- 扫描在后台执行，不阻塞 ExplorerBrowser 所属 STA。导航、切换标签、窗格隐藏或窗口卸载都会取消扫描；旧结果不可覆盖新位置。
- 汇总文件字节数、文件数、子目录数。访问失败与跳过的重解析点计为未读取项，完成结果标明不完整；不会跟随符号链接/联接目录。
- 虚拟 Shell 位置不执行文件系统递归；无法启动时在状态栏说明原因。
- 结果仅供查看，不进入排序、筛选、会话或 `.qdr` 状态；不自动扫描新目录。

## 方案与取舍

选择后台、显式触发的当前目录扫描并显示独立状态栏结果。自动扫描所有可见子目录会在普通导航时制造大量 I/O，与官方性能说明冲突。把大小注入 ExplorerBrowser 原生列需要 Shell 列提供程序或自定义文件视图，会改变已选定的原生 Explorer 操作架构和便携部署，因此不作为本阶段路径。

## 验收

- 纯扫描器测试覆盖空目录、嵌套目录字节/计数、重解析点跳过、取消及权限/IO 不完整结果。
- SettingsSmoke 全量通过，App Release 构建无警告/错误。
- 不运行可见 GUI；F9 输入路由、状态栏布局和实际多窗格取消行为需后续空闲桌面验收。
