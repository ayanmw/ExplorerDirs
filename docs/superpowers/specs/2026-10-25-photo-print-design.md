# 照片打印设计

## 意图

补齐 Q-Dir“文件 → 工具 → 照片打印”能力，让用户从当前文件视图选择照片、设置照片尺寸和每页数量、选择打印机、预览后打印，不必先切换到图片应用。

Q-Dir 官方 FAQ 150 明确列出所选一张或多张图片、照片尺寸、每页张数、打印机选择和打印预览。本项目已有“打印当前文件视图”，它打印目录清单，不能作为照片打印替代。

## 目标和边界

- 新增独立的“打印所选照片…”入口；只处理活动标签中当前选中的项目，不扫描目录或其他窗格。
- 通过 Windows Imaging Component 可解码的图像文件生成打印页；损坏或不受支持的图片逐项说明并允许继续处理有效图片。
- 在本应用拥有的对话框中设置纸张/打印机、每页照片数及照片尺寸；在提交作业前显示分页预览。
- 复用项目现有 WPF 打印基础设施，但不调用文件关联的 canonical `Print` 动词作为主路径。Windows Shell 只承诺调用文件类型注册的打印命令，具体打印行为和 UI 由已注册处理程序决定，不能保证 Q-Dir 提供的照片尺寸、拼页和预览。
- 不改变现有“打印当前文件视图”入口，不自动启动外部图片应用，不新增第三方依赖，不写入系统或文件类型注册表。

## 方案选择

1. **直接调用 Shell `Print` 动词**：实现短，沿用当前图片处理器；但不同文件类型/Windows 配置的命令可能直接打印、打开应用或显示不同 UI，不能稳定提供 Q-Dir 的设置与预览。本方案不满足目标。
2. **应用生成照片打印文档并使用 Windows 打印机接口（采用）**：活动 Shell 视图只提供选择项，WIC 解码图片，WPF 生成可预览的打印文档，Windows 提供打印机和纸张选择。可稳定实现 Q-Dir 公开的工作流，代价是需要维护照片排版和错误提示。
3. **嵌入第三方图片打印组件**：可能缩短布局工作，但新增依赖及进程/授权边界；当前没有依赖或产品证据支持，不采用。

## 交互与实现决定

- 菜单位置：文件菜单中与“打印当前文件视图…”并列，名称为“打印所选照片…”。没有有效选中图片时禁用。
- 对话框采用“左侧设置、右侧分页预览”结构；设置至少包含打印机/纸张、每页照片数、照片尺寸以及“完整显示/填满裁切”适配方式。
- 默认每页一张、完整显示，不裁切原图；照片尺寸默认为适合可打印区域。用户更改纸张、布局或照片尺寸后更新预览。
- 只将可解码的普通文件系统图片加入队列；虚拟 Shell 项目和非图片选中项不送入 WIC。坏图在预览前被列出，用户仍可继续打印其余有效图片。
- 排版和图片读取不阻塞 UI。生成的文档使用冻结后的图像源，不持有输入文件句柄；取消关闭窗口不启动打印作业。
- 打印机与纸张设置必须先确定，再生成预览。窗口保存所选 `PrintQueue` 和已验证的 `PrintTicket`；打印按钮提交相同照片顺序、页面布局、队列及 ticket，不再弹出可更改设置的第二个系统打印对话框。预览使用有界降采样图，提交打印使用相同布局的原分辨率图像。更换打印机或纸张后立即重新生成预览；打印机状态失效或设置无法应用时阻止提交并显示原因。
- 选择打印机与纸张使用窗口内的控件，不调用会立即提交作业的系统 `PrintDialog.ShowDialog()` 作为设置选择器。用户取消或关闭预览窗口不提交打印作业。
- 首版采用有限、可测试的每页布局选项（1、2、4、6、9 张）；照片物理尺寸提供适配纸张和自定义厘米尺寸。具体默认/文案在 UI 验收后再调整，不声称与 Q-Dir 的内部尺寸预设完全相同。

## 可视结构草图

```text
┌────────────────────── 打印所选照片 ──────────────────────┐
│ 打印机 / 纸张       │          分页预览                    │
│ 每页照片数          │  ┌────────────┐ ┌────────────┐       │
│ 照片尺寸            │  │   照片 1   │ │   照片 2   │       │
│ 适配方式            │  └────────────┘ └────────────┘       │
│ 无法读取的图片列表  │              第 1 / N 页              │
│                     │                                       │
│                 [取消]                         [打印…]     │
└───────────────────────────────────────────────────────────┘
```

## 验收边界

- SettingsSmoke 验证照片选择筛选、布局分页、适配/裁切尺寸、坏图逐项处理和取消不提交。
- App Release 构建和完整 SettingsSmoke 必须通过。
- 可见桌面验收确认选择同步、预览、打印机/纸张变化后刷新、取消行为、四窗格窄尺寸和实际打印质量。未完成该验收前不发布，也不宣称照片打印体验与 Q-Dir 相同。

## 本机二进制静态证据（2026-10-25）

本机 Q-Dir 12.79 的 PE 导入名称包含 `PrintDlgW`、`PageSetupDlg`、`OpenPrinterW`/`GetPrinterW`、GDI `StartDocW`/`StartPage`/`EndPage`/`EndDoc`/`AbortDoc` 和 GDI+ 位图创建/绘制函数。它们证明该二进制导入了 Windows 打印与图像 API；没有函数级交叉引用，不能证明这些 API 由 Photo-Print 命令调用，也不能据此还原其尺寸选项或页面布局。设计因此仍依赖官方 FAQ 150 的已公开行为，不把本机 API 导入当作界面兼容证据。
