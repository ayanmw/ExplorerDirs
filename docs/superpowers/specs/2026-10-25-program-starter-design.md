# Program Starter 设计草案

状态：代码已接入，待桌面验收；使用独立便携 INI，并支持导入 Q-Dir 程序项。Store、导入解析/预览 UI、参数展开、安全启动分派及主菜单/快捷键入口已实现；真实桌面交互和安全辅助程序的参数端到端仍待验收。

## 目标

补上 Q-Dir Program Starter：可从当前文件视图启动用户配置的外部工具，并把当前目录、所选文件或指定窗格内容作为参数。该功能与现有 `Ctrl+Q` 快速链接分开，使用 `Ctrl+S` 打开启动器，避免改变 `.lnk` 快速链接的行为。

## 非目标

- 不替换或扩展 `QuickLinks/*.lnk`，不改收藏夹及工作区。
- 不自动导入或执行 `.qdr`、未知 INI 字段或启动项内容。
- 默认不以管理员身份启动，不注册全局快捷键，不修改文件关联或系统 PATH。
- 不在菜单打开时枚举整个文件视图；仅启动用户所选的条目。

## 方案比较

1. **用户已选择：独立便携 Program Starter 配置，导入 Q-Dir 程序项。** 将程序项保存在 profile 的单独 INI；使用“名称 / 程序路径 / 参数 / 工作目录”字段，提供导入预览；保留 `QuickLinks`。可独立设置及备份，也便于复制到别的 Explorer Dirs profile。
2. **只使用标准 `.lnk`。** 复用 Quick Links 的 Shell Link 能力，但不能可靠提供每次启动时动态替换当前目录、多窗格和多选文件参数，因此不满足 Program Starter 的核心差异。
3. **直接复用或修改 Q-Dir.ini。** 表面格式更接近 Q-Dir，但把应用配置耦合到另一产品文件；现有公开资料没有说明完整节名、键名、转义和记录存储结构，无法在不猜测的情况下实现可靠导入，也不应写回该文件。

## 行为

- 在“工具”菜单加入“程序启动器”入口，按 Q-Dir 约定支持 `Ctrl+S`。启动器弹窗显示命令名称，并提供添加、编辑、删除与导入入口；真实菜单布局及焦点留到 GUI 验收。
- 启动项的目标路径、参数模板和可选工作目录均作为配置数据保存。执行前展开已支持的占位符，并以 Windows 参数规则组成参数，路径参数按独立参数引用；不把替换后的字符串重新交给命令解释器。
- 第一版占位符范围对齐官方资料：`%curdir%` / `%curdir1..4%`、`%sel_files%` / `%sel_files1..4%`、`%all_files%` / `%all_files1..4%`，`%fdir%`（运行/打开文件的父目录），以及 `%windir%`、`%sysdir%`、`%desktop%`、`%appdat%`、`%personal%`、`%drive%`。所选/全部文件按明确的 Shell 当前视图快照生成，不使用后台重枚举或隐藏窗格数据冒充活动选择。
- 新格式保存在 profile 下独立 `ProgramStarter.ini`，带格式版本、损坏备份、高版本拒写和外部修改保护；写入模式遵循现有配置 store。
- 官方公开的 Q-Dir 字段顺序为 `Name=Path=Arguments=Work directory`；FAQ 同时提供只有 `Name=Path` 的命令行示例（无参数）、带参数和可选工作目录的行。相对路径允许，带空格路径可用引号包围。官方资料指出启动项保存在 `Q-Dir.ini`；本机 `C:\SoftwareOK\Q-Dir\Q-Dir.ini` 有 `[Program]` 节，但目前只有 `portable_install=1`，没有有效启动项行可作正向文件样本。导入器只解析 `[Program]` 节内 2–4 字段候选项，在预览中显示可导入项、跳过项和原因；不执行导入内容、不写源文件、不把未识别键猜作命令。Q-Dir 实际样本导入验收仍需带启动项的配置文件。
- 字段分隔符本身也是参数可用字符。一个未引用的等号可能是第四字段分隔符，也可能属于命令参数（例如 `--option=value`）；导入器在无法辨认成路径/占位符/引号工作目录时会将该行列为跳过并解释原因，避免静默改变启动参数。需要导入这类参数时，应在 Q-Dir 行中将完整参数字段加引号后重新导入；无需工作目录的三字段行仍可正常导入。
- 本项目将相对程序路径和显式相对工作目录都锚定到应用程序目录，支持同一便携目录结构。Q-Dir 官方 FAQ 仅明确相对程序路径示例，没有说明第四字段工作目录的相对锚点；因此后者是 Explorer Dirs 的确定性规则，不宣称与 Q-Dir 内部解析完全一致。
- 默认普通用户启动。未来如需管理员启动，作为每条启动项的显式设置并在启动时走系统 UAC 流程；不以按住 Ctrl 的全局键盘状态隐式提权。
