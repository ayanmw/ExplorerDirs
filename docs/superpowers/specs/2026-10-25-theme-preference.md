# 全局主题偏好设计

## 目标

提供 profile 级 `System`、`Light`、`Dark` 主题选择，默认 `System`。`System` 跟随 Windows 应用颜色偏好，并在设置变化时更新；显式 Light/Dark 在本程序内保持固定。设置保存在便携 INI，不从或写入应用注册表。

## 范围

- 主题是全局 profile 偏好，多个本程序窗口立即共用。
- 首阶段将主题应用到 WPF 窗口、菜单、工具栏、导航和状态栏资源；保留用户已有紧凑密度、地址栏样式和各标签视图配置。
- ExplorerBrowser 原生文件视图继续由 Windows Shell 管理颜色；此设置不强制它使用 WPF 主题色，也不解决导入后文件列表偶发黑底。
- `.qdr` 导入/导出不读取或修改全局主题。
- 不更换按钮图标，不加入自定义逐项文件颜色规则。

## 交互与数据

- 入口放在“工具 → 选项 → 主题”，三个互斥项为“跟随系统”“浅色”“深色”。
- 配置文件为 profile 级 `Theme.ini`，格式含版本及 `Mode=System|Light|Dark`。缺失时使用 `System`，损坏时先备份并回退；未知未来格式或并行外部修改时拒绝覆盖。
- 解析后的系统主题与用户所选偏好分开保存；系统颜色事件只重新解析 `System`，不改写 INI。
- Windows API 或主题变化通知暂不可用时，系统模式沿用上次成功解析值，首次解析失败则使用 Light。

## 验证边界

- SettingsSmoke 验证缺省、合法值、损坏备份、未来版本保护、并行编辑保护和系统模式解析；QDR 导入/导出既有回归必须保持通过。
- App Release 构建验证 WinRT API 接线和 WPF 资源编译。
- 真实系统切色、菜单控件样式、焦点、非客户区标题栏及 ExplorerBrowser 原生文件区分别留待可见验收；源码/Smoke 不能宣称其通过。
