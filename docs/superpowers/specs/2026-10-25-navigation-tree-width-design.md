# 可调整目录树宽度设计

## 意图

Q-Dir 的目录树宽度可以按使用习惯调整。Explorer Dirs 当前把逐窗格树固定为 160 DIP、共享树固定为 190 DIP；这项设计为两种模式提供可拖动分隔条，并把宽度保存在便携 INI 中。

## 范围

- 逐窗格模式中，每个窗格分别保存树宽度；共享树模式单独保存一份宽度。
- 默认逐窗格宽度为 160 DIP，共享树为 190 DIP；有效范围为 96–600 DIP。
- 只有用户完成拖动后才保存；显示/隐藏树、切换树模式和调整窗口大小不写入新值。
- 使用独立的 `NavigationTreeWidths.ini`，避免旧版本覆盖未知配置；写入前检查磁盘内容未被其他进程改动，损坏文件先备份。
- `.qdr` `TreeNsplit` 不纳入本项，继续等待其格式语义的独立证据。

## 非目标

- 不改变目录树导航、焦点停靠点或共享/逐窗格模式语义。
- 不宣称与 Q-Dir 的 `TreeNsplit` 字段兼容。
- 不进行可见 GUI 验收；本轮只做源码、配置与构建验证。

## 实现选择

使用 WPF `GridSplitter` 调整现有树/文件视图列；窗口级 store 保存共享宽度和四个窗格宽度。测试覆盖默认、范围验证、配置往返、损坏备份和新版本保护。真实拖动手感、窄窗格布局和重启后的可见结果留待桌面验收。
