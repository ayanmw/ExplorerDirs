# Q-Dir 对比截图与当前进度

依据用户提供的 Explorer Dirs 与 Q-Dir 12.79 并排截图。截图包含个人目录和项目文件名，不复制到仓库。

| 截图中差异 | 此次处理 | 仍需验证或后续工作 |
| --- | --- | --- |
| Q-Dir 有顶部功能菜单，原型只有几个按钮。 | 增加文件、标签页、视图、工具菜单；常用命令仍在快捷工具栏。 | 后续菜单项随真实文件操作扩展。 |
| Q-Dir 顶部有一排布局快捷图标。 | 同一组布局定义驱动菜单与图形按钮：单、两种双、两种三、四窗格。 | 更多用户常用布局与可保存布局组合。 |
| Q-Dir 的标签右键能新建、复制、关闭其他和恢复关闭。 | 标签右键及快捷键加入这些操作；列表右键也可在新标签打开目录。 | 标签滚动、拖动排序、固定标签与完整会话状态。 |
| Q-Dir 文件夹和文件有图标及部分状态叠加标记。 | 从 Windows Shell 按文件夹/扩展名获取类型图标。 | 单文件自定义图标、Git/SVN/云同步状态叠加标记。 |
| Q-Dir 文件列表右键混合标签命令与第三方 Shell 命令。 | 先提供本程序的标签和路径右键菜单。 | Windows Shell 右键扩展（Git、SVN、压缩软件等）尚未嵌入。 |
| Q-Dir 的面包屑、导航栏和状态栏更密集。 | 地址栏改为随窗格伸缩，维持菜单、工具栏、地址栏、标签、列表、状态的整体顺序。 | 面包屑、历史、收藏夹、紧凑排版和多标签溢出处理。 |

本轮代码的完成状态以构建与启动烟测为准。以上菜单动作和图标仍需要在用户的日常目录与窗口尺寸下人工预览。
