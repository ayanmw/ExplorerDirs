# 通知事件队列协调实验

2026-11-06。本批只修改 NativeProbe，不接入正式应用，不更新预览。

新增按导航访问对象隔离的 FIFO 事件队列：删除后同名重建、连续改名及大小写改名保留所有事件，同时可判断工作是否仍是相关路径的最新工作。完成旧工作只释放仍属于它的键；离开访问后永久失效并清空记录。失效判断不是文件系统对象身份验证，也不能撤销已经发出的 Shell 通知。

无窗口命令 `--projected-change-ledger-smoke` 通过：同名重建、改名链、原始大小写、旧访问拒绝、4096 条并发生产的严格序号及释放/关闭归零。原先缺少实现的编译失败记录在 `src/.state/projected-ledger-before.log`，实现后 Release 构建零错误零警告。

现有原生通知桥实验接入了队列的删除派发、行消失后的确认及真实视图销毁后待办失效检查。`src/.state/projected-ledger-native.log` 中 1029 行增删改名、精确 8KB 更新、不增加枚举、选区保留及销毁清理子断言通过。共享输入活动触发守卫，整条命令退出 1；不记完整隔离验收通过，未切换共享桌面或注入输入。

剩余门槛：真实 FileSystemWatcher 接线，过期事件的文件系统重协调，同名替换的确切对象身份，导航期间的提交时序，队列背压与突发合并，以及完整应用四窗格、同根多视图、分组验收。FIFO 暂无容量上限，只用于实验。不能简单跳过所有旧事件：创建 A 后改名 A→B，旧创建即使失效也可能需要补足原生视图状态。
